# Preserved visualization attempt

The first `READ_COUNT_SUMMARY.html` used the standard JoSIM plotter and its
fixed `Time (seconds)` x-axis label, although the four x values represented
read counts. The page, its QA record, and its plot manifest are retained
here. The final page is rendered by `analysis/render_summary.py` with the
declared categorical read-count x-axis; no raw file was changed.
