## Question and fixed topology

Record the four registered mask paths through two local branches and a shared
second GAP input. This is not a T1 experiment and does not include MERGE,
COMMON_SL, JSL, or old `jtl2` cells.

```text
XBVM1 → XBQ1 → XCB1 → XACC1 → XGAP1 ─────┐
                                         ├→ GAP2_IN → XGAP2 → FINAL_OUT → R_TERM(2Ω)
XBVM2 → XBQ2 → XCB2 → XACC2 ────────────┘
```

`XACC1` and `XACC2` are local accumulators. `XGAP1` is the sole inter-BVM GAP
cell. `XACC2.OUT` and `XGAP1.OUT` directly share `GAP2_IN`; `XGAP2` is the
final accumulator. No measurement link element is inserted.

## Authorized matrix and stimulus

Exactly four independent immutable physical runs: `N0_00`, `N1_01`, `N1_10`,
`N2_11`. Each has two BVMs and six PWL sources. All masks receive the same
WRITE0/CONTROL/WRITE1 preamble; only the final READ mask differs. Bit order is
`b1b0`, with `b1=BVM1`, `b0=BVM2`. Timing and source values are frozen in
`REGRESSION_MATRIX.json`.

- WRITE0: 50–61 ps; both WL and BL = −100 µA.
- CONTROL: 70–81 ps; both WL and SE = +100 µA.
- WRITE1: 90–101 ps; both WL and BL = +100 µA.
- FINAL READ: 110–121 ps; active mask bits get WL and SE = +100 µA; BL = 0.
- Every edge uses 1 ps rise/fall and a 9 ps plateau.
- `.tran 0.01p 200p 0p`.

No READ repetition, timing skew, parameter changes, new GAP stages, extra load,
T1, timestep sweep, or follow-up is authorized.

## Registered probes and arithmetic

The raw probes include six stimulus branch currents; both BVM storage and
R-loop junction P/V/I, branch currents, and SL outputs; BQ1/BQ2 BJ1–BJ3 P/V/I,
inductor I/V and output nodes; CB1/CB2 BJ1/BJ2 P/V/I, inductor I/V and outputs;
ACC1/ACC2 BJ1 P/V/I, L1/L2 I/V and outputs; XGAP1/XGAP2 BJ1 P/V/I and L1/L2
I/V; `GAP2_IN`; and `FINAL_OUT`, `V(R_TERM)`, `I(R_TERM)`. The exact signal list
is generated by `scripts/common.py` and hash-bound in machine preflight.
`XACC2` has no separate `ACC2_OUT` node: its second port is the shared
`GAP2_IN`, which is probed directly, while `I(L2|XACC2)` retains its branch
contribution.

Mechanical analysis windows are half-open: PRE `[101,110)`, FINAL READ
`[110,121)`, POST `[121,200)`, and combined READ-response `[110,200)` ps. For
each registered JJ/window, phase progression is derived from independently
unwrapped raw radians at the actual first/last stored samples; the corresponding
signed voltage-time area uses that same JJ, direction, endpoints, and actual
timestamps. Terminal raw and N0_00-subtracted signed areas use the exact stored
grid with no interpolation. If grids differ, the paired subtraction is
`UNKNOWN`.

Voltage extrema and their sample times may be tabulated as direct observations.
No post-hoc threshold, event classifier, SFQ count, population verdict, or
mechanism/location conclusion is authorized in the operator phase. Timestep
convergence and robustness remain `UNKNOWN`.

## Incident — execution aborted before registered matrix

On 2026-09-23, a preflight helper incorrectly treated JoSIM's `--sanitycheck`
option as a no-solve parser check. JoSIM proceeded to run a transient simulation
of the temporary `N0_00` preview deck (return code 0). Its stderr reported
`Unknown device/node ACC2_OUT; Cannot store results for this device/node.` The
temporary directory was automatically removed, so no raw/log artifact was
retained. This was not launched by `run_matrix.py` and is not valid evidence.
No registered run directory or accepted raw exists. The preflight helper has
been changed so static-only checks never invoke JoSIM. This experiment is
aborted pending user direction; do not resume or count this temporary result.
