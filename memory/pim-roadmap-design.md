## 二、Phase 1 深度分析：BVM→BQ 耦合

### 2.1 电路实测参数

#### BVM SL 输出链路（bvm_cell.cir）

```
N6 → L_PSL(0.5pH) → R_SL(12Ω) → N8 → L_SL(0.4pH) → SL端口
```

| 结 | Area | IC (jjmit) | 角色 |
|----|------|-----------|------|
| JM1 | 1.2 | 120µA | 开关结，并联 6Ω 阻尼 |
| JM2 | 1.4 | 140µA | 非开关结 |
| JS1 | 0.74 | 74µA | 检测结 (R-Loop) |
| JS2 | 0.74 | 74µA | 检测结 (R-Loop) |

- WL/BL/SE 驱动：100µA 电流脉冲
- SL 负载：12×jjmit(area=3.2) 串联堆栈
- 存储状态："1" = P(JM1) ≈ ±0.94×2π，"0" = P(JM1) ≈ 0

#### BQ 输入级（bq_cell.cir）

```
IN → Lin(0.8pH) → BJs(IC=50µA, area=0.5) → L1(3.91pH) → L2(3.91pH) → BJL2(IC=54µA) → L0(1.32pH) → OUT
                    ↓ BJL1(IC=36µA, RJ1=33Ω) → GND
```

| 元件 | Area | IC | 备注 |
|------|------|-----|------|
| BJs | 0.5 | 50µA | 检测结，RN=32Ω |
| BJL1 | 0.36 | 36µA | DC偏置路径，RJ1=33Ω 阻尼 |
| BJL2 | 0.54 | 54µA | 输出隔离，RJ2=22Ω 阻尼 |
| IBias | — | 35µA DC | RB=6Ω |
| 独立触发阈值 | — | **90µA** 脉冲 | 含偏置下 BJs 达到 IC |

### 2.2 阻抗不匹配量化

```
BVM SL输出阻抗:  Z_out ≈ 130Ω
  = R_SL(12Ω) + 结动态阻抗(~100Ω) + 寄生感抗(~18Ω @ 1THz)

BQ 输入端阻抗:   Z_in  ≈ 350Ω
  = BJs亚能隙阻抗(320Ω = R0/area = 160/0.5) ∥ 偏置网络等效阻抗

电流传递率 = Z_out/(Z_out+Z_in) = 130/480 ≈ 27%
```

**结果**：BVM 存储环 ~55µA 读出信号 → BQ 输入端仅收到 **~15µA**。
BJs IC=50µA，触发缺口 = 50-15 = **35µA**。

> **额外发现**：bq_cell.cir 注释中曾写 "BVM SL output impedance (~15 ohm)"，后来修正为 ~130Ω。
> 15Ω 仅是 DC 路径 R_SL(12Ω)+RS(3Ω)，忽略了结的动态阻抗（~115Ω @ SFQ 频率）。
> 这解释了为什么初期预计耦合可行但实际失败。

> **JJ 模型兼容性因素**：memory 记录显示 BVM 在 V0 参数（Ic×RN=0.25mV）下才能稳定工作，
> 而当前统一使用 jjmit（Ic×RN=1.6mV）。混合模型（BVM=V0 + BQ=jjmit）已验证可行，
> 可能也是耦合失败的一个贡献因素——需要在 Phase 1 中同时测试混合模型配置。

### 2.3 路线 A：低 IC 检测结

#### 参数重设计

```
目标：BJs IC 从 50µA 降至 20µA

bq_cell.cir 修改:
  BJs  area: 0.5 → 0.20  (IC: 50µA → 20µA,  RN: 32Ω → 80Ω)
  BJL1 area: 0.36 → 0.14 (IC: 36µA → 14µA)
  BJL2 area: 0.54 → 0.22 (IC: 54µA → 22µA)
  IBias:      35µA → 14µA (维持 70% 偏置比)
  RJ1:        33Ω → 82Ω    (匹配新 RN 以维持 Bc≈1)
  RJ2:        22Ω → 52Ω    (匹配新 RN)

触发验证:
  I_到达(15µA) + IBias(14µA) = 29µA > IC_BJs(20µA) ✓
  裕度: (29-20)/20 = 45%
```

#### 参数扫描范围

| 参数 | 范围 | 步长 |
|------|------|------|
| BJs area | 0.15 - 0.30 | 0.05 |
| IBias | BJs_IC × 0.5 - 0.9 | 0.1×IC |
| RJ1 | 50Ω - 150Ω | 25Ω |

#### 风险评估

| 风险 | 概率 | 缓解 |
|------|------|------|
| 低 IC 下热噪声误触发 | 低 | 4.2K, IC=20µA 时噪声 ~0.3µA << 9µA 裕度 |
| BJL1/BJL2 阻尼变化导致输出波形退化 | 中 | 参数扫描找最优 RJ1/RJ2 |
| BVM 输出电流随存储状态变化 | 中 | 测试 "0" 和 "1" 两种读出场景 |

### 2.4 路线 B：变压器耦合

> **重要发现**：JoSIM 的 `TX` 元件是传输线模型（`TD=200p, Z0=2Ω`），**不是**互感变压器。
> 变压器耦合方案需要使用 JoSIM 的 **K 元件**（互感耦合），语法为 `K<name> L<pri> L<sec> <coupling_coeff>`。

#### K 元件互感设计

```spice
* K-耦合变压器 1:2 (匝数比 n=2)
L_PRI IN GND 2p       ; 初级电感 2pH
L_SEC OUT GND 8p       ; 次级电感 8pH (n²×L_PRI = 4×2 = 8pH)
K_TX L_PRI L_SEC 0.9   ; 耦合系数 k=0.9
* 等效匝数比 n = sqrt(L_sec/L_pri) = sqrt(8/2) = 2
* 电流增益 = n × k = 2 × 0.9 = 1.8
```

```
匝数比 n=2:
  I_out = n × I_in × k = 2 × 15µA × 0.9 = 27µA
  I_total = 27µA + IBias(35µA) = 62µA > IC(50µA) ✓

匝数比 n=3:
  I_out = 3 × 15µA × 0.9 = 40.5µA
  I_total = 40.5µA + 35µA = 75.5µA > IC(50µA) ✓ (裕度 51%)
```

#### 参数扫描

| 参数 | 范围 |
|------|------|
| n (匝数比) | 1.5, 2, 2.5, 3 |
| k (耦合系数) | 0.7, 0.8, 0.9 |
| L_PRI | 1p, 2p, 5p |

#### 风险评估

| 风险 | 概率 | 缓解 |
|------|------|------|
| JoSIM TX 模型与实际不符 | 中 | 先单独验证 TX 频率响应 |
| 互感引入额外延迟 | 低 | SFQ 脉宽 2ps, TX 延迟 ~0.5ps |
| Layout 面积增加 | 高（但对仿真无影响） | 仅关注电气特性 |

## 三、Phase 2：T1 全加器验证

### 3.1 当前状态

- T1 电路: 18节点，11 JJ，3端口 (I, CLK, C/S输出)
- 已验证: CLK 隔离测试 (5/5)，sfq_gen_clk (4/4)，sfq_gen_i (10/10)
- **未验证**: 完整加法真值表

### 3.2 真值表测试计划

| A (I脉冲数) | B (外部SFQ) | 预期 Sum (S) | 预期 Carry (C) | 测试方式 |
|-------------|------------|-------------|---------------|---------|
| 0 | 0 | 0 | 0 | 仅 CLK，无 I，无外部 |
| 1 | 0 | 1 | 0 | I=1 SFQ，无外部 |
| 0 | 1 | 1 | 0 | I=0，外部 A=1 SFQ |
| 1 | 1 | 0 | 1 | I=1 SFQ + 外部 A=1 SFQ |

### 3.3 驱动方案

- I 端口: sfq_gen_i 产生 0/1 SFQ 脉冲
- CLK 端口: sfq_gen_clk 产生时钟
- 外部加数: sfq_gen 经 JTL 延迟后注入 T1 数据输入端
- 时序: 数据先于时钟 (2ps 脉宽规则)

## 四、Phase 3：4×1 BVM 阵列

### 4.1 阵列拓扑

```
BL ──────┬──────────┬──────────┬──────────┬──────────┐
         │          │          │          │          │
WL0 ── BVM[0]   BVM[1]    BVM[2]    BVM[3]      │
         │          │          │          │          │
SE0 ────┤       SE1 ───────┤       SE2 ───────┤    SE3
         │          │          │          │          │
SL0 ─────┤       SL1 ───────┤       SL2 ───────┤    SL3
         │          │          │          │          │
        GND        GND        GND        GND        GND

共享: BL (Bit Line), 所有 cell 共用
独立: WL[i] (Word Line), SE[i] (Sense Enable), SL[i] (Sense Line)
```

### 4.2 测试序列

1. 写 BVM[0]="1", BVM[1]="0", BVM[2]="1", BVM[3]="0"
2. 依次读 BVM[0]→BVM[3]，验证数据正确
3. 半选测试: WL[1]=100µA 但 SE[1]=0，验证 BVM[0] 不受干扰
4. 串扰测试: 写 BVM[0] 时读 BVM[1]，验证无干扰

## 五、创新性研究方向

### 5.1 BVM 多涡旋态计算存储

利用 JM1 可存储 2, 3...N 个涡旋的特性（相位 = n×2π），实现模拟计算。
**可行性**: 中 — 需研究多涡旋写入的精度和稳定性。

### 5.2 SFQ 深度流水线

利用 JTL 确定性延迟 (~1ps/stage) 构建无时钟偏移的流水线。
**可行性**: 高 — JTL 已有完整模型和测试数据。

### 5.3 T1 级联进位链

多个 T1 级联做 ripple-carry adder，C 端口直连下一级 I 端口。
**可行性**: 高 — T1 的 C(进位输出) 端口已设计好。

### 5.4 超导 PIM 指令集

定义 SFQ 原语: READ(col), WRITE(col, val), ADD, COMPARE, SEARCH。
**可行性**: 中 — 需要阵列控制电路，可作为 Phase 5+ 规划。
