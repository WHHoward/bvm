## 1. 实验模式

在运行前声明一种模式：

| 模式 | 用途 | 允许的结论 |
|---|---|---|
| `calibration` | 建立指标、方向、窗口和容差 | 校准事实；不得评价候选优劣 |
| `exploratory` | 寻找现象、边界和下一实验 | 观察与假设；不得宣布 Gate PASS |
| `candidate` | 按冻结规范评估候选 | 可给 PASS/FAIL/INCONCLUSIVE |
| `reproduction` | 复现历史运行 | 复现一致性；不自动恢复旧物理结论 |

`candidate` 必须记录 `METRIC_SPEC_V2` 路径与 SHA-256。规范未冻结时降级为 `calibration` 或 `exploratory`。

## 2. 运行身份与不可变产物

建议结构：

```text
test/final/<route>/runs/<run-id>/
  manifest.yaml
  inputs/
  raw/<case>/<step>/run-01.csv
  logs/
  metrics_v2/
  plots/
  gate/
  analysis.md
```

执行以下规则：

- 使用包含日期、路线、问题和序号的唯一 run ID。
- 目标目录已存在时停止；创建新 ID，不覆盖。
- 保存主网表、全部 `.include`、模型和生成参数的实际快照或完整哈希闭包。
- 保存 Git HEAD、dirty 状态和差异文件清单；dirty 运行不能只记录 HEAD。
- 保存 `build/josim-cli` 的绝对路径、版本和二进制 SHA-256。
- 保存分析脚本、指标规范和信号方向表的版本/哈希。
- 所有重复运行都保留；不得在比较哈希后删除第二份证据。
- `/tmp` 只能放可丢弃中间文件，不能成为唯一研究证据。

字节哈希一致只表示同一输入得到了相同文件，不等于物理正确、指标正确或时间步收敛。

## 3. 预注册问题

每个 run 只设一个主要问题，并在看结果前记录：

- 主假设；
- 至少一个替代解释；
- 自变量、因变量和冻结条件；
- 哪些观察对应 PASS、FAIL、INCONCLUSIVE；
- 扫描范围、点数预算和停止规则；
- pre/activity/post/read-state 时间窗的选择规则。

窗口必须由激励时间和校准规范确定。若仿真结束仍未稳定，应延长仿真或判不确定，不能移动窗口寻找有利端点。

## 4. 对照与输入

按研究问题选择，结论级接口实验通常需要：

- 完全匹配的零输入控制；
- read0 与 read1；
- 已知正确的正控制；
- 反极性输入；
- 理想输入、保存波形重放、完整级联三种证据强度；
- 真实输出负载与标准两级 JTL；
- 更细时间步。

零输入控制除激励外必须保持网表、模型、初态、偏置、负载、仿真长度和测量窗口一致。

单次因果实验优先使用非周期 `pwl(...)`。周期 `pulse(...)` 必须在 manifest 标成 `periodic_regression`，不能代替单事件验证。

## 5. 测量合同

为每个被审计 JJ 注册：

- 层次名称；
- `P(...)` 列；
- 直接 `V(B...)` 列或明确的正负端点；
- 相位正方向和电压正方向；
- pre/activity/post 窗口；
- 对应的下游 JTL 级。

相位与电压面积必须来自同一 JJ、同一端点、同一方向和同一时间窗。若历史 CSV 缺少结电压列，只能重算相位，不能补造双证据。

## 6. 数据有效性

分析前检查：

- JoSIM 退出码为零，且日志无未处理 solver 错误或警告；
- CSV 非空，列完整，无 NaN/Inf；
- 时间严格递增并达到预期终点；
- 请求步长、实际时间列和仿真时长已记录；
- 激励、控制和输出列存在；
- 事件后有足够稳定区间；
- 原始文件哈希与 manifest 一致。

这些条件失败时标记 `INVALID`。`INVALID` 描述实验产物不可判，不是电路功能 `FAIL`。

## 7. 收敛与扫描

对名义通过点、最接近边界点和代表失败点，至少比较三个预先声明的时间步，例如 0.1/0.05/0.025 ps。比较：

- 净相位圈数；
- 同 JJ 电压面积；
- 事件时间；
- 稳定平台误差；
- BVM 读前/读后漂移；
- 最终 Gate 分类。

分类随步长变化时判 `INCONCLUSIVE`。

参数扫描先做粗扫并验证单调性，再细化边界。两个离散点只能支持“已测点行为不同”；只有在适用范围内验证单调性后，才能把它们写成边界区间。多个参数同时变化时，不得把结果归因于其中一个元件。

## 8. 结果与停止规则

每次分析分开记录：

- `Observed`：由文件直接计算或读取的事实；
- `Inferred`：与数据相容、尚待对照的机制；
- `Unknown`：缺少的证据；
- `Verdict`：PASS/FAIL/INCONCLUSIVE/INVALID；
- `Next discriminating experiment`：能区分主要替代解释的最小实验。

出现方向未知、缺控制、缺稳定窗、相位—面积不一致、无加载 JTL、步长分类变化或规格未冻结时，停止升级结论。

负面路线结论必须限定模型、激励、负载、参数范围、时间步和指标版本。不要把“预算内未找到通过点”写成普遍不可能。
