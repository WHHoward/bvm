# 第一部分：物理基础（超导电子学的 ABC）

## 1. 超导：电阻为零的导体

普通导线有电阻，电流流过会发热损耗。**超导材料在低温下电阻变为零**——电流可以在里面无损耗地流动，而且一旦转起来就会一直转（这就是超导存储器的基础，后面会用到）。

超导电路里有一个直觉上很反常识的点：**信号主要以"电流"和"磁场"的形式存在，而不是"电压"**。这和我们熟悉的电子学（电压驱动的数字逻辑）不一样，是理解后面所有内容的关键。

## 2. 约瑟夫森结（JJ）——这个项目的核心元件

**结构**：两层超导体中间夹一层极薄的绝缘体（三明治）。

**它有两个神奇的性质**（1962 年约瑟夫森预言并验证）：

**性质一：临界电流 IC。** 流过结的电流只要**低于** IC，结就是一个完美导体（零电阻，就像不存在一样）。**一旦超过** IC，结就"跳变"到一个有电压的状态（就像突然变成了一个电阻）。

**性质二：超导电流由"相位差"驱动，而不是电压。** 这里要用到你熟悉的相位概念。

### 2.1 相位是什么（快速回顾 + 超导语境）

你熟悉 sin(ωt + φ)：φ 就是相位，描述"波走到哪一步了"。两个超导体之间的相位差记作 φ。

**第一约瑟夫森方程**（直觉版）：结里的电流由相位差决定：

```
I = IC · sin(φ)
```

**第二约瑟夫森方程**（直觉版）：结两端的**电压等于相位变化的速度**：

```
V = (Φ₀/2π) · dφ/dt
```

> **把相位想象成水表指针**：结两端有电压 = 指针在转。指针每转一圈（相位前进 2π），就记录下"流过一个磁通量子"。

### 2.2 磁通量子 Φ₀——为什么这个东西能做数字电路

**磁通量子 Φ₀ = 2.07 × 10⁻¹⁵ Wb**，是自然界的最小磁场单位（量子化的）。超导电路里，磁场只能以 Φ₀ 的整数倍存在——**就像计算机里的 bit 只能是 0 或 1，不能是 0.5**。

结翻转一次，恰好释放/吸收**一个** Φ₀。因为量子化，**每次翻转携带的"能量包"完全一样大**——这就是数字性（确定性、可复制）的物理来源。

## 3. SFQ 脉冲：超导世界的"1"

当结翻转（相位前进 2π），会产生一个约 2 皮秒（10⁻¹² 秒）的电压脉冲，携带恰好一个 Φ₀。这个脉冲叫 **SFQ 脉冲**（Single Flux Quantum，单磁通量子脉冲）。

- **有脉冲 = 数字 1，没脉冲 = 数字 0**
- 脉冲在结与结之间"传递"，就像击鼓传花——**RSFQ 逻辑门**（与门、或门、触发器等）就是靠脉冲的到达顺序和有无来做计算
- 因为每次脉冲都恰好是一个 Φ₀，信号**永远不会衰减失真**——这是它比电压逻辑优越的地方

## 4. 结的动态和阻尼（βc）——为什么有的结会"失控"

结翻转时，它内部的电容和电感会让它像一个钟摆/秋千：推它一下，它会**来回摆动**。摆多久取决于阻尼：

- **无阻尼（欠阻尼）**：推一下，荡几十个来回才停
- **有阻尼（过阻尼）**：推一下，荡一两下就停

**阻尼大小由参数 βc 描述**（βc 越大越欠阻尼）。我们的模型（jjmit）里所有结的 βc ≈ 5.4，**天生欠阻尼**——所以标准电路里都要给结加"刹车"：一个**并联的电阻+电感网络（RB+LRB）**，把振铃压下去。

> **这是整个项目的第一个关键概念**：结翻转后如果停不下来，相位就会持续前进（持续滑移），产生"一堆"磁通而不是"一个"磁通——数字性就被破坏了。

## 5. 电路语言速成（把忘了的电感电容捡回来）

我们网表里的元件只有 4 种，用直觉记：

| 元件 | 记法 | 直觉 |
|---|---|---|
| 电阻 R | `R1 2 0 10` | 欧姆定律 V = IR；消耗能量 |
| 电感 L | `L1 2 3 2p` | **抵抗电流突变**（电流不能瞬间变化）；存储磁场 |
| 电流源 I | `I1 0 1 pwl(...)` | **规定流过多少电流**（像水泵，不管下游怎么变） |
| 约瑟夫森结 B | `B1 2 3 jjmit area=0.5` | 见 §2：电流上限 IC，超过就跳变 |

两个关键直觉：
- **电感"不能突变"** 是超导电路里一切时序的基础（信号从一个结传到下一个结需要时间）
- **电流源 = 通量泵**：如果电流源持续往一个结里灌电流，结翻转后电流还在灌，就会一直翻——这是后面 BQ 失败的核心原因之一

## 6. 怎么读一个 SPICE 网表（计算机学生视角）

网表就是"电路的配置文件"，和你写过的配置文件/代码结构对应：

| 网表语法 | 计算机类比 |
|---|---|
| `.include xxx.cir` | include 头文件 |
| `.subckt NAME a b c ... .ends` | 定义函数/模块（端口=参数） |
| `.param X=5p` | 定义常量 |
| `B1 2 3 jjmit area=0.5` | 实例化一个结（节点 2 和 3 之间，参数 area） |
| `I_WL1 0 WL1 pwl(...)` | 驱动信号（随时间变化的波形） |
| `.tran 0.1p 110p` | 仿真设置：每 0.1 皮秒算一步，算到 110 皮秒 |
| `.print P(B1\|XSUB)` | 输出哪些信号（P = 相位，单位 Φ₀） |

**仿真流程**：网表 → josim-cli（求解器）→ CSV（每个时间步每个信号的数值）→ sfq_metrics.py（提取指标）。

# 第二部分：项目在做什么

## 7. 最终目标与本次研究的问题

**最终愿景**：用超导电路做"内存计算"（PIM）——存储和计算都在超导域完成，速度比电子计算机快几个数量级。

**当前研究的问题**：我们设计了一个超导存储器 **BVM**，但它"读出"时给出的是一个**模拟电流信号**（约 68µA、几十皮秒）；而超导数字逻辑（RSFQ）需要的是**数字 SFQ 脉冲**。两者之间需要一个**接口**——就像 ADC（模数转换器）在模拟传感器和数字计算机之间的角色。

```
BVM（模拟读出电流）  ──??接口??──▶  RSFQ 数字逻辑（SFQ 脉冲）
```

**论文的核心问题**：怎么把这个模拟电流**可靠地**转换成一个（且恰好一个）SFQ 脉冲？

## 8. BVM：超导存储器

**存储原理**：一个超导环。电流在环里打转会产生磁场；因为磁通是量子化的，环里只能存**整数个磁通量子（涡旋）**。有没有涡旋 = 存的是 0 还是 1。

- **写入**：WL（字线）+ BL（位线）电流把涡旋"推"进环里
- **读出**：SE（读使能）电流触发开关结，把"环里有多少涡旋"变成"流出多少电流"
- **实测行为**（这是我们用仿真量出来的）：读"1"时给出约 68µA 的电流脉冲（随负载 44-98µA 变化），脉冲本身约 7-11 皮秒宽，而且**正负振荡**（不是干净的单个凸起）；源阻抗约 40Ω

> 重要事实：BVM 的读出**天生是模拟电流**，不是 SFQ 脉冲——它像"水位传感器"输出压力，而不是"数字温度计"输出数字。中间必须有转换器。

## 9. BQ：我们失败的第一次尝试（8 轮实验）

BQ 是我们最初设计的"缓冲器"，想让它完成 ADC 的角色。它有一个输入结 **BJs**，设想是：BVM 的电流灌进来，超过 BJs 的临界电流 IC，它翻转一次 = 输出 1 个 SFQ。

**为什么 8 轮实验全部失败**（三个根因，都记在证据链里）：

**根因 1：裸结没装刹车（欠阻尼）**
BJs 没有任何阻尼网络，翻转后停不下来（βc≈5.4 天生欠阻尼，见 §4）。标准电路（JTL）每个结都有 RB+LRB"刹车"，BQ 的 BJs 没有。
→ 结果：一翻转就"荡个不停"，相位持续滑移（实测：一次读出滑移 6.27 个磁通量子，而不是 1 个）。

**根因 2：电流源是"通量泵"（水龙头一直开）**
BVM 的读出是持续几十皮秒的电流。结翻转后，电流还在灌——就像水龙头开着，杯子溢出了水还在流。
→ 结果：滑移量由"水龙头开了多久"决定（实测 602-829 个量子/300 皮秒），完全不可控，和"1 个 SFQ"毫无关系。

**根因 3：输出级力气不够**
就算 BQ 翻转了，它输出的脉冲电流只有约 100µA，而下游标准逻辑（JTL）需要约 250µA 才能触发。
→ 结果：下游什么都收不到（实测 JTL 收到 0 个脉冲）。

**还有一条数学上的死路（L_J 矛盾）**：想降低 BJs 的 IC 来匹配 68µA 输入？降低 IC 会让结的等效电感变大（L_J = Φ₀/(2π·IC)），输入电流被电感吃掉更多——**降低阈值的好处被电感增加完全抵消**，数学上自相矛盾。

> **结论**：BQ 的拓扑结构（裸结输入 + 并联输出）不适合这个接口，我们停止了"改参数"的尝试——这是 GPT 审计给我们的纪律：**决策表，而不是试到成功**。

## 10. DCSFQ_BVM：我们的新方案

**DCSFQ**（DC-to-SFQ）是 ColdFlux 标准元件库里现成的元件：设计意图就是"DC/慢电流电平 → 一个 SFQ 脉冲"。它天然就是我们要的"ADC"骨架：

- **每个结都有阻尼网络**（刹车装齐了）→ 解决根因 1
- **输出结是 250µA 标准水平**（与下游 JTL 同规格）→ 解决根因 3
- **是阈值判别器**（电流超阈值才触发一次）→ 从机制上避免根因 2 的持续泵

**我们的改动**：DCSFQ 的输入级设计给约 225µA 的信号用，而 BVM 只给 ~68µA——**灵敏度不匹配**。所以我们把输入级两个结从 225µA **缩放到 80µA**（area 参数 2.25 → 0.8），就像把传感器灵敏度调高来匹配信号。输出级保持 250µA 不动（冻结，防止又推不动 JTL）。

新元件叫 **DCSFQ_BVM**，文件在 `circuits/interface/DCSFQ_BVM.cir`。

# 第三部分：我们做过的每一件事（时间线 + 为什么）

## 11. 为什么先"冻结基线"（2026-08-06，Step 0）

**背景**：开始改 BQ 之前，我们发现仓库里同一个实验有三套互相矛盾的记录：旧的实验日志说 BJs 翻转了 1.00 个量子，GPT 审计说 −0.00001，我们自己跑出来是 +6.27。**没有可信的尺子，就不知道任何改动是变好还是变坏。**

**排查出的根因**：
1. **模型时代混用**：7 月中旬前 BVM 用的是旧的 V0 模型（能量参数 0.25mV），后来换成 jjmit（1.6mV）。旧记录 0.94 是 V0 时代的值，已经无法复现
2. **计数口径错误**：把"相位穿过 1.0 的瞬间"当成了"结果"（实际净变化是 +6.27）

**冻结动作**（把尺子固化）：
- 固定：基线网表 + 4 个关键文件的 SHA-256 + 仿真器版本 + 5 个指标定义（net_delta/fast_events 等）+ 唯一提取脚本 `sfq_metrics.py` + md5 确定性验证（同一网表跑 3 次结果逐字节一致）
- 产出 `BASELINE.md`，之后所有实验都按这个口径

> **为什么值得**：现在论文里每个数字都能被任何人复现——审稿人跑一遍得到同样的 md5、同样的数字。

## 12. BQ v4：最后一个确认实验（2026-08-06，Step 1）

我们把 BQ 的 IC 顺序反转（想让输出结先触发而不是输入结先触发），独立验证 **Gate 未通过**：输出反而比旧版差 5.5 倍。这证实了**问题在拓扑结构、不在参数**——BQ 路线正式排除。

## 13. 路线转向：为什么选 DCSFQ 骨架（2026-08-06）

8 轮失败 + 数学矛盾（L_J）证明"修 BQ"没有出路。DCSFQ 骨架在结构上解决了全部三个根因（§10）。这是**你拍板的方向**：设计新元件，而不是继续修 BQ。

## 14. Phase 0：先测行为，再定参数（2026-08-06）

设计定稿前，我们做了 4 组实验回答 4 个问题（**原则：所有设计参数来自实测，不靠推算**）：

**P0.0 BVM 负载扫描**——"BVM 到底能给出什么信号？"
5 种负载测出接口规格：电流 43.9-97.8µA（随负载变）、脉冲宽 7-11ps（不是以为的 30-40ps）、源阻抗 40Ω（不是以为的 15Ω）。**两个"常识假设"被实测推翻。**

**P0.1 现有 DCSFQ 行为测试**——"这个元件怎么工作？"
- 输入 0-150µA 全不触发（现有元件阈值 >150µA，与 BVM 完全不匹配 → 缩放必要）
- **边沿触发确认**（关键发现）：持续输入 148 皮秒，结相位恒定不累积；事件只发生在输入"变化"的瞬间。**类比：门铃（按一下响一下）vs 水龙头（开着一直流）——DCSFQ 是门铃**。这排除了"需要门控"的顾虑
- 但 300µA 输入时一次爆发 8 个事件 → **过驱动会多脉冲，必须工作在近阈值**

**P0.2 分流标定**——"缩放到 80µA 后，68.4µA 输入真正耦合进结的有多少？"
**只有 28.5%**（19.5µA）。输入电流大部分被一个到地的电感（L2）分流走了，而且方向还和结的偏置电流相反。→ 起点元件在 68.4µA 下不触发（自洽：偏置+耦合 < 临界电流）。**这暴露了输入网络需要重新设计——Phase 1 的核心任务。**

**P0.3 确定性**——结论可信吗？5 组关键运行 md5 全部一致 ✅

**Phase 0 的收获**：三个设计假设被实测修正（脉冲宽、源阻抗、耦合结），阈值目标定为 45-55µA（下限是读"0"时的干扰电流 40µA，上限是过驱动上限 1.5×IC）。

## 15. P2：存储侧验证——多涡旋问题（2026-08-09）

**背景**：最终目标"读1 → 恰好 1 个 SFQ"隐含一个前提：存储状态稳定、可重复、读不破坏。但基线数据显示 BVM 写入后不是 1 个涡旋而是 **6 个**（多涡旋）。

**四项验证结果**：
1. 写1 → 稳定在 +6 涡旋，读电流 78µA；写0 → −6 涡旋，读电流仅 17µA（**对比度 4.6 倍**，判别裕度充足）
2. 多次循环可重复（波动 <1%）✅
3. 读不破坏状态（但 **120µA 的读驱动会擦除数据** → 读驱动必须 ≤100µA，这是级联实验的硬约束）
4. **单涡旋工作点不存在**（写驱动从 80 调到 120µA，都是 0 涡旋直接跳到 6 涡旋）

**结论**：存储侧"可用但要如实描述"——多涡旋不致命（判别器只看电流大小，6 涡旋的 78µA 稳定可重复），但论文里"单涡旋存储"的说法不成立，且读驱动幅度成为设计约束。

## 19. 论文目标（为什么这一切值得）
