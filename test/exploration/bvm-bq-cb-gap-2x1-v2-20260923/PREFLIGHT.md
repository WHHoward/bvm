## Question and fixed topology

Record the four registered mask paths through two local branches and a shared
second GAP input. This is not a T1 experiment and does not include MERGE,
COMMON_SL, JSL, or old `jtl2` cells.

```text
XBVM1 → XBQ1 → XCB1 → XACC1 → XGAP1 ─────┐
                                         ├→ GAP2_IN → XGAP2 → FINAL_OUT → R_TERM(2Ω)
XBVM2 → XBQ2 → XCB2 → XACC2 ────────────┘
```

`XACC1` and `XACC2` are local accumulators. `XGAP1` is the sole inter-BVM GAP
cell. `XACC2`'s second port and `XGAP1.OUT` directly share `GAP2_IN`; `XGAP2`
is the final accumulator. There is no separate top-level `ACC2_OUT` node. No
measurement link element is inserted.

## Authorized matrix and stimulus

Exactly four independent immutable physical runs: `N0_00`, `N1_01`, `N1_10`,
`N2_11`. Each has two BVMs and six PWL sources. All masks receive the same
WRITE0/CONTROL/WRITE1 preamble; only the final READ mask differs. Bit order is
`b1b0`, with `b1=BVM1`, `b0=BVM2`. Timing and source values are frozen in
`REGRESSION_MATRIX.json`.

- WRITE0: 50–61 ps; both WL and BL = −100 µA.
- CONTROL: 70–81 ps; both WL and SE = +100 µA.
- WRITE1: 90–101 ps; both WL and BL = +100 µA.
- FINAL READ: 110–121 ps; active mask bits get WL and SE = +100 µA; BL = 0.
- Every edge uses 1 ps rise/fall and a 9 ps plateau.
- `.tran 0.01p 200p 0p`.

No READ repetition, timing skew, parameter changes, new GAP stages, extra load,
T1, timestep sweep, or follow-up is authorized.

## Registered probes and arithmetic

The raw probes include six stimulus branch currents; both BVM storage and
R-loop junction P/V/I, all nine BVM inductors I/V, six BVM resistors I/V, and
SL outputs; BQ1/BQ2 BJ1–BJ3 P/V/I, Lin/L1/L2/L3 I/V, active RJ1/RJ2/RJ3 I/V,
IB2 current, and output nodes; CB1/CB2 BJ1/BJ2 P/V/I, L1–L4 I/V, RJ1 I/V, IB1
current, and outputs; ACC1/ACC2 BJ1 P/V/I, L1/L2 I/V, RJ1 I/V, and IB1 current;
XGAP1/XGAP2 BJ1 P/V/I, L1/L2 I/V, RJ1 I/V, and IB1 current; `GAP2_IN`; and
`FINAL_OUT`, `V(R_TERM)`, `I(R_TERM)`. CB RJ2 is commented out in the source,
so it is not probed. The exact 223-signal list is generated by
`scripts/common.py`, checked against the active subcircuit element inventories,
and hash-bound in machine preflight.
`XACC2` has no separate `ACC2_OUT` node: its second port is the shared
`GAP2_IN`, which is probed directly, while `I(L2|XACC2)` retains its branch
contribution.

Measurement semantics reference `docs/research/METRIC_SPEC_V2.md` v2.0.0; an
exact copy and the v1 incident record are included under `references/`.
Each registered phase/area pair uses a direct same-JJ P/V branch, literal
subcircuit pin order, `reporting_direction=+1`, and
`voltage_to_phase_sign=+1`; the mapping registry explicitly keeps BQ/sJTL
mapping acceptance `UNVERIFIED` for this fixture. Phase-area residuals are
descriptive only because the specification has no frozen residual tolerance.
No pass/fail or event-count label is derived from these values.

After each solve, `independent_verify.py` recomputes endpoint phase and
trapezoidal areas directly from the raw CSV using a separate Decimal arithmetic
path. Its tiny implementation-reproduction tolerances are frozen in
`REGRESSION_MATRIX.json`; they test analyzer arithmetic only and do not classify
the physical circuit or replace the UNFROZEN phase-area acceptance tolerance.

Mechanical analysis windows are half-open: PRE `[101,110)`, FINAL READ
`[110,121)`, POST `[121,200)`, and combined READ-response `[110,200)` ps. For
each registered JJ/window, phase progression is the direct raw JoSIM P last-minus-
first value in radians (the solver output is already unwrapped; no modulo or
additional re-unwrapping is applied). The corresponding signed voltage-time
area uses that same JJ, direction, endpoints, and actual timestamps. Window
membership uses exact decimal parsing of stored seconds tokens. Time integration
uses the actual stored time differences in seconds. Terminal raw and N0_00-
subtracted signed areas use the exact stored grid with no interpolation. If grids
differ, the paired subtraction is `UNKNOWN`. Artifact QA requires a first sample
at 0 ps and actual coverage through at least 199.99 ps (`STOP-DT`).

Voltage extrema and their sample times may be tabulated as direct observations.
No post-hoc threshold, event classifier, SFQ count, population verdict, or
mechanism/location conclusion is authorized in the operator phase. Timestep
convergence and robustness remain `UNKNOWN`.
