## 一、项目概况

JoSIM 是超导电子学 SPICE 语法电路仿真器。本项目用它仿真基于 ColdFlux RSFQ 设计方法的超导数字电路，目标是构建「存储(BVM) → 量化/缓冲(BQ) → 逻辑(标准元件) → 运算(T1 全加器)」的完整仿真流水线 + 发表论文。

**论文方向（Paper A）**: BVM→BQ 接口设计——BVM 慢读出电流（~68µA）能否触发 BQ 产生离散可控 SFQ。文献空白已确认。

## 五、冻结物理结论（8/6，引用需注明）

1. **BJs 任何过驱动即滑移**（1.4×IC 即进入电压态滑移，从未干净单翻转）
2. **βc 不变量**: jjmit 所有结 βc≈5.44 与 area 无关；JTL 干净翻转靠外部 RB+LRB 阻尼 + 70% 偏置，BQ 两者皆无 → **这是 BQ 与标准单元行为差异的关键结构原因**（H6 的理论基础）
3. **电流源注入 = 通量泵**: 滑移量由驱动水平/窗口决定，与 SFQ 计数无对应
4. **L_J 矛盾**: IC↓→L_J↑→传递↓，低 IC 方案自相矛盾
5. **K 元件**适合 MHz-GHz 连续波，不适合 ps 级脉冲
6. **BVM 写入多涡旋**（+5.93 SFQ 非 0.94）
7. **确定性**: 固定步长 md5 验证
