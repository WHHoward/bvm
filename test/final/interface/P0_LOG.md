## 1. 决策门判定（G1-G5）

| 门 | 判据 | 实测 | 结论 → 下一步 |
|---|---|---|---|
| G1 触发位置 | 首个 fast_events≥1 的 IIN | 0-150µA 全不触发；**阈值 ∈ (150, 300]µA**（300µA 为多滑移爆发 B3×8/B1×7） | 现有 225µA DCSFQ 与 BVM 68.4µA 完全失配 → 缩放正确；**干净单 SFQ 需近阈值过驱动** |
| G2 边沿 vs 电平 | sustained 150ps 保持期是否累积 | **边沿触发**：bump/sustained 事件数与时序逐位一致，B2 平台 ~6.76 Φ0 恒 148ps 零累积 | **方案一（最小缩放）确认，无需门控** |
| G3 接口规格 | P0.0 表 + 补测 | 见 §2 | 阈值目标修订为 **45-55µA**（见 §3） |
| G4 分流系数 | 增量 I(L3)/I(L1) | **0.285**（<0.3 警示线；输入方向与偏置环流相反，仅 ~19.5µA/68.4µA 耦合向结支路） | **Phase 1 需调整输入网络**（L2/L3 或下调 IC），V2 扫描裁决 |
| G5 确定性 | md5 ×2 | **5/5 一致**（md5+SHA-256 双算法 + JSON 嵌入值交叉核对） | ✅ Phase 0 结论可引用 |

## 2. 接口规格（BVM → DCSFQ_BVM，实测）

| 量 | 值 | 来源 |
|---|---|---|
| I_SL R1 峰值（负载相关） | **43.9-97.8µA**（50Ω→短接） | P0.0 |
| 冻结基线 68.41µA 的构成 | **8-JJ 链 + BQ 输入分流**（纯链 79.55µA；BJs Ic=50µA 分走 ~11µA） | P0.0 异常定位 |
| R1 脉冲 FWHM | **6.8-11.2ps**（12Ω 6.8ps / 8jj 9.3ps；30-40ps 是 SE 驱动窗口而非脉冲宽） | Task 6 补测 |
| 源阻抗 Zth | **≈39.6-41.2Ω**（Thevenin，拟合输入点见下；原 ~15Ω 假设废止） | P0.0 + Task 6 复核 |
| 开路电压 Vth | ≈3.88-4.0mV | 同上 |
| 读1/0 差分裕度 | ≥31µA（窗口定义 12/50Ω 最差）/ 43-97µA（脉冲内） | P0.0 |
| R0 窗口 SE 边沿振铃 | **±40µA**（低负载，与 R1 峰值同量级）→ 判别需按时序，阈值不能只高于 1.4µA | P0.0 |
| 存储扰动 | JM1 ≈ −5.91 SFQ 负载不变（读不破坏状态） | P0.0 |

**Thevenin 拟合输入**（(R_load, I_SL 峰值)）：(1Ω, 96.18µA)、(12Ω, 73.95µA)、(50Ω, 43.91µA)；1/I = (R+Zth)/Vth 最小二乘 → Zth=41.2Ω, Vth=4.0mV（P0.0 记录 39.6/3.88，差异为拟合定义，同量级）。

## 3. 设计修订（进 spec）

1. **阈值目标 25µA → 45-55µA**（P0.1: 过驱动 ~1.4× 即多滑移爆发 → 读1 过驱动需 ≤1.5×；P0.0: 需高于 R0 边沿振铃）
2. **输入网络待调**（G4: 0.285 耦合 < 0.3）→ Phase 1 增加 L2/L3 调整或 B1/B2 下调至 ~0.6（V2 扫描裁决，不无限迭代）
3. **极性待验证**（P0.1: 输入耦合进 B2 支路、与 B1 偏置相反；真实 BVM 级联极性 V4 验证，可能影响响应结）
4. **68.4µA 定义修正**：是"8-JJ 链+BQ 输入"加载值；接口设计按负载相关范围 44-98µA 取裕度

## 4. Phase 1 验证链（V1-V4b，待计划修订）

V1 偏置稳定 → V2 阈值判别扫描（含 L2/L3 输入网络变体）→ V3 JTL 接收 → V4 BVM 级联（含极性验证）→ V4b 去负载链对照。最终 Gate 不变：读1 → 恰好 1 个被 JTL 接收的 SFQ；读0 → 0。
