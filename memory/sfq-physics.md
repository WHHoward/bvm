# SFQ 脉冲物理与仿真约定

## 基本关系

| 量 | 关系 | 严格含义 |
|---|---|---|
| 磁通量子 | \(\Phi_0\approx2.0678\ \mathrm{mV\,ps}\) | 电压时间面积单位 |
| Josephson 电压关系 | \(V=(\Phi_0/2\pi)d\phi/dt\) | 同一 JJ 的相位导数与结电压 |
| 净相位圈数 | \(\Delta\phi_{\rm rad}/(2\pi)\) | 该 JJ 的净绕转，不自动等于下游事件或环 fluxoid 数 |
| 电压面积 | \(\int V_Jdt/\Phi_0\) | 与同 JJ、同方向、同时窗的净相位圈数交叉校验 |

JoSIM `P(...)` 输出是 raw phase rad。绘图时除以 \(2\pi\) 只得到 phase turns，不能直接命名为 SFQ count。

## 脉冲宽度和幅度

不存在脱离拓扑、偏置、源阻抗和负载的“必须 2 ps”规则。旧测试台曾观察到某些 5 ps、3 Ω 注入会过驱，而某些 2 ps 输入得到更接近单次响应；这只是特定网表的项目观察，不能外推为普适物理定律。

任何新接口应分别扫描并记录上升沿、宽度、面积、源阻抗、峰值和真实负载。只有稳定窗相位、同 JJ 电压面积、下游 JTL 和收敛共同满足冻结规范时，才判合格事件。

## 钟控单元时序

ColdFlux 部分被测钟控单元要求数据事件先建立内部状态，再由时钟读取。具体 setup/hold、极性和端口语义属于单元与测试台规格，不能把“数据必须先于时钟”当作所有 RSFQ 电路的普适定律。每个单元应由其网表、手册和完整时序扫描确定。

## 活动检测与证据层级

- 电压阈值、相位导数或相邻采样差只能定位候选活动区。
- `|V|>200 µV` 不是普适 SFQ 判据；阈值必须由版本化校准规范确定。
- 一个 JJ 的净相位约一圈只支持本地事件候选。
- 加载后的 JTL 逐级平台、read0/read1、重复读、状态保持和步长收敛用于更高层 Gate。
- Load JTL 的某一结相位总量不能脱离参考窗、控制和轨迹直接当作输出脉冲数。

## 注入电路

以下只是历史测试台形状，不是默认设计：

```spice
V_IN IN 0 pwl(...)
R_IN IN N1 3
L_IN N1 SFQ_IN 0.5p
```

使用前必须验证它与真实 BVM 的波形、源阻抗和加载反馈是否可比。理想源重放不能替代完整级联。
