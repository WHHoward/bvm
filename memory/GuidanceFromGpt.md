## 一、当前项目的准确定位

项目的基础设施和组件级工作已具备良好基础，但系统主线 **BVM→BQ 接口尚未成功**。

### 已验证的事实

1. JoSIM 可正常构建和运行；现有 `ctest` 的 23 个上游/基础集成测试全部通过。
2. BVM 单元、多个 ColdFlux 标准单元、SFQ 发生器均已有独立仿真记录。
3. 标准 BQ 可以在独立强驱动条件下发生约瑟夫森结相位滑移并产生输出活动。
4. BVM→标准 BQ 的直接级联没有形成可靠、离散、可被下游 JTL 接收的 SFQ 输出。
5. 低 IC BQ 版本和当前实现的 K 元件互感路线均未解决级联问题。

### 绝不能误称为已完成的事项

1. **没有可用的 BVM→BQ 接口。** 当前没有证据表明单个 BVM cell 能可靠驱动 BQ 并输出至少一个可用 SFQ。
2. **BQ 还没有被证明是“电流→可变 SFQ 数”的量化器。** 它目前更接近具有阈值和饱和行为的缓冲器/开关。
3. **BQ v4 仅是设计假设，尚未实现或仿真。** 仓库中不存在计划所列的 `circuits/qb/bq_cell_v4.cir`、独立测试和 BVM 级联测试。
4. 因此，Paper A 尚不能按“接口解决方案成功”写作；目前最多是“问题表征与候选接口探索”的阶段。

## 三、对 BQ 现象的正确解释

### 1. 不要把持续相位滑移直接称作量化

独立 BQ 在强、持续或较长脉冲驱动下出现数十至数百个 SFQ 的累计相位变化，可能表示 JJ 进入持续电压态。这个数量通常依赖于驱动持续时间、阻尼、偏置和仿真窗口，而非稳定地编码输入电流幅度。

合格的“电流→可变 SFQ 数”量化器至少要满足：

1. 在定义的有限输入窗口内产生有限数量的离散脉冲；
2. 下游 Load JTL 实际接收到相同数量（或明确的固定映射）；
3. 输出数随输入幅度单调、可重复，并有无输入/低输入时的零输出；
4. 对输入宽度、偏置和器件参数扰动有可报告的工作窗口。

在这些条件满足以前，将当前 BQ 叫作“阈值缓冲器”或“候选量化器”更严谨。

### 2. BQ v4 是待验证假设，不是根因定论

v4 的核心假设是：BJL1 的低 IC 及其到地路径过早导通，吞噬 BJs 之后向输出链传播的能量；故提高 BJL1 IC、适度提高 BJL2 IC 并调整阻尼/输出电感。

这个假设合理，但提高 BJL1 IC 也可能使 DC 回流或偏置稳定性变差。实施 v4 后不能只看 OUT 电压；每个测试都必须记录：

- BJs、BJL1、BJL2 的相位和电压；
- BJL1 支路电流、输入节点电流、偏置节点电流；
- BQ 输出及 Load JTL 两个结的相位；
- 偏置建立阶段是否稳定、是否有无输入自发翻转。

## 四、建议执行顺序（严格优先级）

### Step 0：冻结并校准基线口径

这是所有后续工作的前置条件。

1. 选定当前 `test_bvm_bq_baseline.cir` 作为冻结基线，记录 commit hash、JoSIM 版本、`.tran` 设置和模型文件 hash。
2. 重跑独立 BVM、独立 BQ、BVM→BQ 基线各至少两次。
3. 编写一个可重复的指标提取脚本或命令，输出相位差、峰值电流和阈值事件；不要依赖人工读图。
4. 解释并修正文档中“BJs 约 1 SFQ”与当前“约 0 SFQ”的差异。

**Gate**：每个关键指标都有唯一、明确的测量定义，重复运行一致。

### Step 1：实施并独立验证 BQ v4

创建：

- `circuits/qb/bq_cell_v4.cir`
- `test/final/qb/test_bq_v4_standalone.cir`
- `test/final/single_bvm_qb/test_bvm_bq_v4.cir`

先执行独立测试，按以下顺序：

1. 无输入、仅偏置稳定性测试；
2. 标准 SFQ 注入测试；
3. 有限宽度电流脉冲扫描（例如 70/90/110/130/150 µA）；
4. 下游 Load JTL 的实际 SFQ 接收计数；
5. BJL1/BJL2 支路与偏置状态诊断。

**Gate**：v4 必须在独立测试中产生有限、可重复、被下游 JTL 接收到的输出；若仅出现持续电压态，不进入级联测试结论阶段。

### Step 2：再做 BVM→BQ v4 级联

仅在 Step 1 通过后进行。

1. 保持 BVM 与冻结基线完全一致，只替换 BQ 子电路。
2. 分别报告 BVM 读出“0”和“1”的结果，避免只展示一个成功波形。
3. 报告 BVM SL 电流、BQ 输入节点电流、三只 BQ JJ 相位和 Load JTL 相位。
4. 至少进行两次重复运行，且包含未写入/低信号对照。

**成功 Gate**：单 BVM cell 的目标读出状态稳定产生至少 1 个被 Load JTL 接收到的 SFQ；非目标状态不误触发。

### Step 3：根据 v4 结果作路线决策

| v4 结果 | 应采取的行动 |
|---|---|
| 独立测试失败 | 回到 BQ 拓扑/偏置设计，不做 BVM 级联归因 |
| 独立成功、级联失败 | 重点研究 BVM 输出波形、源阻抗、输入匹配；不应归咎于 BQ 内部 |
| 级联成功但只固定 1 SFQ | 将其定位为数字读出缓冲器，调整系统目标，不再声称可变计数 |
| 级联成功且可控多 SFQ | 进行完整量化、鲁棒性和模型扰动扫描 |
| v4 仍失败 | 停止围绕原 BQ 做简单缩放；转向专用“慢电流→受控 SFQ”接口 |

### Step 4：若需要转向专用接口

设计目标应从“让现有 BQ 被迫工作”改为“匹配 BVM 的约 30–40 ps 慢电流波形”。候选方向：

1. 过阻尼阈值 JJ / DC-to-SFQ 检测器；
2. 先整形为快 SFQ，再由 JTL/BQ 接收；
3. 重设计 BVM 输出级，降低源阻抗或提高可用电流；
4. 以输出有限脉冲数为约束的专用积分/泄放拓扑。

此前 K 元件实验只能说明**当前 K 拓扑、参数和负载下不成功**，不能推广为“互感变压器不适合所有 SFQ 脉冲接口”。

## 九、关于 BVM 与 BQ 的进一步技术建议（2026-07-19）

### 1. 重新定义接口问题

建议不要继续把核心问题定义为“怎样让现有 BQ 接收 BVM 输出”，而应定义为：

> **怎样将 BVM 的慢、小读出电流可靠地转换为一个受控的数字 SFQ 事件。**

BVM 本身未被证明存在功能错误；当前的主要矛盾是接口功能不匹配：

- BVM 的 SL 是约 30–40 ps 的慢电流读出，且读出量会随负载改变；
- 当前 BQ 在强驱动下可能持续相位滑移，在弱驱动下不动作，不能天然保证输出有限、可计数的脉冲；
- BQ 的 BJL1 直接从 BJs 后的 node 2 接地，与通向 BJL2/OUT 的支路竞争输入事件能量。

### 2. 第一优先级：表征 BVM 输出，而不是先继续改 BQ

在选定同一读出序列、同一 JJ 模型后，对 SL 端进行负载扫描。建议至少比较：短接或极低阻抗、小电阻、12Ω、几十欧姆、当前 8-JJ 串联负载，以及直接连接候选接收器。

每个点必须同时记录：

- `I(L_SL|XBVM)` 与 `V(SL)`；
- BVM 读“0”和读“1”的差分波形；
- 负载实际获得的峰值电流、脉冲宽度与能量；
- BVM 的存储相位是否仍保持正确。

当前基线在 BVM 和 BQ 之间串有 8 个“非翻转”JJ。它可能是必要的负载模型，也可能是实际接口的额外障碍；在完成直接连接与负载扫描的 A/B 对照前，不应假设它无害或有害。

该实验的产物应是接口规格，而不是一张波形图：`I_peak`、有效宽度、源阻抗/负载依赖性、读“1”与读“0”的差分裕度。

### 3. 单 BVM cell 的正确近期目标

BVM 是二值存储器。对单个 cell，近期成功标准应为：

```text
读出“1” → 恰好 1 个被下游 JTL 接收到的 SFQ
读出“0” → 0 个 SFQ，且没有误触发
```

不要要求单个 BVM cell 的读出电流直接编码为“可变数量的 SFQ”。如果未来系统需要求和，优先采用多个 cell 各自生成一个数字 SFQ，再通过 MERGE、计数器或时钟化逻辑完成累加；不要先把多个慢模拟读出电流直接相加并期待当前 BQ 量化。

### 4. 推荐主路线：有门控的近阈值 JJ 比较器

比继续缩放 BQ 更值得优先尝试的路线是专用读出比较器：

```text
                        ┌→ JTL / DFF / 计数逻辑
BVM SL 电流 ─┐          │
             ├→ 近阈值检测 JJ ─→ 单个 SFQ
读使能偏置 ──┘          │
                        └→ 复位/抑制持续电压态
```

设计原则：

1. 检测 JJ 的静态偏置保持在临界电流以下；
2. 读“1”时，BVM SL 的附加电流使其越过阈值；读“0”仍低于阈值；
3. 偏置只在有限读窗口打开，事件发生后关闭或复位，避免 JJ 持续进入电压态；
4. 输出接 JTL，以 Load JTL 相位而非 OUT 电压峰值计数；
5. 先在理想有限电流脉冲下验证工作窗口，再接入真实 BVM SL。

ColdFlux 的 DCSFQ 单元可作为拓扑参考，但不能未经验证直接接到 BVM：其输入级临界电流约 225µA，远高于当前 BVM 读出量级。更合理的做法是基于其“DC/慢信号触发 SFQ”的思想，设计面向 BVM 电流水平的过阻尼、可门控版本。

### 5. BQ v4 应如何定位和改进

BQ v4 仍值得实现，但它是低成本的**假设验证**，不应成为唯一主路线。

除了既定的 BJL1/BJL2 IC 调整，还应做以下对照：

1. 只提高 BJL1 IC，隔离“回流结过早翻转”这个假设；
2. 只调整 BJL2 和输出网络，检查输出级是否才是限制；
3. 将 BJL1 的 DC 回流/偏置功能从 BJs 后的 node 2 解耦，例如改至更靠后的偏置节点，或用较大电感/电阻使其在 SFQ 时间尺度上隔离；
4. 每种变体都做无输入偏置稳定性、有限脉冲扫描和 Load JTL 输出计数。

若 v4 只有持续电压态、没有有限且被下游接收的脉冲，则应判定“现有 BQ 拓扑不适合 BVM 读出”，停止简单 IC 缩放。

### 6. 若最终需要多级电流→多 SFQ 的量化

这不应依赖单 JJ 的自由持续滑移。更适合的方向是：

```text
BVM/阵列电流 → 超导积分（磁通累积）环 → 时钟控制读出/释放 → SFQ 序列
```

积分环储存有限磁通，时钟控制释放次数，因此输出脉冲数量有明确的物理量化依据。它比“在有限脉冲中让 JJ 自行连续翻转”更可控，也更容易定义鲁棒性窗口。

### 7. 建议的资源分配与近期路线

将主要工作投入以下顺序：

1. BVM 输出/负载扫描，获得真实接口规格；
2. BQ v4 作为快速排错实验；
3. 同时设计和验证有门控的近阈值 JJ 比较器；
4. 先打通单 BVM cell 的 `1/0 → 1/0 SFQ`；
5. 成功后再研究阵列计数、积分量化或 PIM 计算链路。

总体判断：现有 BQ 更像一个不受控的阈值缓冲网络。专用读出比较器在功能上更匹配 BVM 的物理输出，因此应作为项目的主攻方向。

## 十、基于冻结证据链的再校准建议（2026-08-06）

> **状态更新**：§九写作时 BQ v4 仍未实施；截至 2026-08-06，v4 已完成独立验证且 Gate 未通过。本节以 `docs/HANDOVER.md`、`BASELINE.md` 和论文证据链中冻结的 jjmit 结果为准，更新近期路线。

### 1. 当前可依赖的结论及其边界

在冻结的模型、网表和指标口径下，直接 BVM→BQ 路线已经被可靠排除：BVM 读“1”在 SL 给出约 68.4µA、30–40ps 的电流；原 BQ 的 BJs 产生慢电压态滑移而非离散 SFQ；BQ v4 虽消除了 BJL1 先触发，但 BJL2 在低输入下不触发，无法驱动下游 JTL。

“冻结”应只用于网表、原始数据和观测指标，**不应被表述为脱离模型与拓扑的普适物理定理**。论文建议使用如下限定语：

> 在 jjmit 模型、当前 BQ 拓扑和所测参数范围内，未观察到离散且可控的 SFQ 输出。

同理，K 元件实验只能排除当前 K 拓扑和参数组合；“任何过驱动必然滑移”也应限定为当前 BQ 输入级及已测驱动范围。

### 2. H6 值得做，但不得直接照搬 JTL 数值

H6（给 BJs 增加 JTL 式 RF 阻尼和预偏置）是最低成本、最有物理依据的下一步，因为 BQ 的 BJs 缺少标准 JTL 所具有的外部阻尼网络。

但 `THmitll_JTL` 的 B1/B2 面积为 2.5（250µA），BQ 的 BJs 面积为 0.5（50µA）。按 JTL 内部的同一比例公式：

```text
RB = 6.859Ω / area
LRB = (RB / 2Ω) × 1.13pH + 0.5pH
```

对于 BJs area=0.5，更合理的**首个同标度起点**是 `RB≈13.7Ω`、`LRB≈8.25pH`，而不是直接复制 JTL 的 `2.74Ω`、`2.05pH`。后者会产生约五倍更强的归一化分流，可能仅仅把 BVM 信号耗散掉。

H6 应至少包含三个受控变体：

1. 同标度 `RB+LRB`（13.7Ω、8.25pH 起点）；
2. 强阻尼对照（直接复制 JTL 的 2.74Ω、2.05pH）；
3. 纯电阻阻尼对照，用于先隔离“阻尼是否有效”，再评估串联电感的物理实现。

所有三组均只改 BJs 输入级；不要同时改变 BJL1、BJL2、L0 或下游负载，以保持因果归因。

### 3. H6 的 Gate 必须拆为输入级与输出级两段

不要把“下游 JTL 有没有收到”作为 H6 的唯一判据。先证明 BJs 能产生干净事件，再讨论 BQ 输出级。

| 阶段 | 目标 | 必需输入与观测 | 通过条件 |
|---|---|---|---|
| H6-A：输入级 | BJs 从滑移变为一次有限翻转 | 单次 `pwl(...)` 输入；`P(BJs)`、`V(BJs)`、BJs 实际支路电流 | `net_delta≈1 SFQ`、`fast_events=1`、无窗口依赖的长滑移 |
| H6-B：输出级 | BJL2 和接收器接收该事件 | 沿用 H6-A 已通过的 BJs；观察 BJL1/BJL2/JTL 相位 | BJL2 与下游接收器均有有限、离散、可重复事件 |

H6-A 必须使用一次性 `pwl(...)` 脉冲，不能使用周期 `pulse()`；后者会将多次激励和振铃累积混入单事件结论。

### 4. 预偏置必须显式设计并测量

当前 BQ 的 `IBias` 接入 node 3，而非 BJs 的输入节点。因此不能把“外部源为 35µA”直接等同于“BJs 已预偏置 35µA”。

H6 应增加或明确一条可测的 BJs 偏置支路，并在无输入、读“0”、读“1”三种条件下记录 BJs 的实际工作电流。偏置窗口应在读出结束后关闭或使单元复位，避免 BJs 长时间保持电压态。若无法测得并控制该工作点，H6 的“预偏置”假设就没有被实际检验。

### 5. H7 是 H6 失败后的直接主路线

若 H6-A 无法得到干净单翻转，应立即停止 BQ 参数迭代并进入 H7：带读窗口的、过阻尼的近阈值 JJ 比较器 / DC-to-SFQ 接口。

单 BVM cell 的近期系统目标应严格定义为：

```text
读出“1” → 恰好一个由下游 JTL 接收到的 SFQ
读出“0” → 零 SFQ，且无误触发
```

对于未来阵列累加，优先让多个 BVM cell 各自产生数字 SFQ，再使用 MERGE、计数器或时钟逻辑求和；不要将多个慢读出电流直接叠加到现有 BQ 以期获得可变量化。若确实需要多 SFQ 输出，应转向“磁通积分环 + 时钟控制释放”的专用结构，而非依赖 JJ 自由滑移。

### 6. BVM 的多涡旋状态是独立验证项

在 jjmit 配置下，JM1 写入后稳定在约 +5.93 SFQ。这不自动等价于 BVM 失效，因为当前读“1/0”仍表现出强电流对比；但它不能被不加验证地称为“单涡旋存储”。

该项不应阻塞 H6/H7，却应另立验证：

1. 写“0”/“1”后的稳态相位与读出电流；
2. 多次写读循环的可重复性；
3. 读操作是否破坏状态；
4. 写脉冲和模型选择是否能得到单涡旋工作点。

### 7. 修正文档和后续排序

`memory/project-todo.md` 中 S0.3 已显示 `scripts/sfq_metrics.py` 完成，但 I3 仍标为未完成；应将 I3 标注为“已由 S0.3 覆盖”，或明确 I3 代表另一套自动化需求，避免任务状态矛盾。

截至 2026-08-06 的建议优先级：

1. 做一次 BJs 单脉冲电压/电流诊断，量化滑移机制；
2. 进行 H6-A：面积同标度阻尼、强阻尼和纯电阻对照；
3. 仅在 H6-A 通过后做 H6-B 输出级/JTL 验证；
4. H6-A 失败则立即转 H7 门控过阻尼比较器；
5. 并行进行 BVM 多涡旋读写一致性验证；
6. 在 H6 或 H7 得到正结果后，完善论文的正向方案章节。
