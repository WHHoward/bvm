D2 Final: BVM→QB Direct Connection (no jj320 load)

JS=22μA | Rshunt=10Ω | IBIAS=40μA | Lin=0.8pH | QB = sole SL termination

D2 Results Summary

BVM→QB direct connection WORKS. No separate jj320 load needed — QB input serves as the SL termination.
BVM write/read function preserved (PJM1=13.4rad, NDRO intact).

QB response:
• IJS peaks at 22.1μA (right at IC=22μA) — current flows through QB as expected
• PJS reaches 1.3rad (0.20Φ₀) — responds but weak
• VJS very low — junction doesn't fully enter voltage state

Limitation: BVM read current pulse is ~2-3ps wide. QB phase can only accumulate ~0.2Φ₀ during this window before the pulse ends.
Full 2π SFQ requires either a longer pulse or a latching mechanism.
For multi-BVM reads (2-4 cells simultaneously), accumulated current 2-4× stronger should produce proportionally larger QB response.

Key result: BVM→QB electrical interface is proven functional. The current DOES flow into QB. The remaining challenge is converting the short BVM current pulse into a full SFQ output — which is the "modification" the MVM paper refers to but doesn't detail.
