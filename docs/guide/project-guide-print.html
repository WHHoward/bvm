先读这一页：我们究竟在做什么

一句话概括：

本项目正在验证并设计一个接口，把 BVM 在“读 1”时产生的、随负载变化的几十微安电流波形，转换成恰好一个能被标准 JTL/RSFQ 逻辑接收的 SFQ 事件；转换后的脉冲才交给 T1 等数字单元计数、求和与产生进位。

系统数据流是：

存储                         模拟/量子接口              数字传输与计算

BVM ──状态相关电流──▶ BQ 或 DCSFQ_BVM ──SFQ──▶ JTL ──▶ T1 / RSFQ 逻辑
 │                         │                         │
 │ 保存双稳态环流          │ 当前研究的主要缺口        │ 接收已量化的事件
 └─不是普通 CMOS RAM       └─不是普通电压 ADC          └─不是慢电流量化器

项目不是在修改 JoSIM 求解器本身。对 Git 树的核验显示，研究工作没有改动 src/、include/、cmake/、根 CMakeLists.txt 或上游 CTest；项目增加的是电路网表、实验、分析脚本、论文材料和文档。可以把它理解为：

  • JoSIM 是“解释器 + 数值运行时”；
  • .cir 网表是“程序”；
  • CSV 是“程序运行轨迹”；
  • 本项目的研究对象是这些网表能否实现所需物理行为。

一个会改变研究路线的审计发现

JoSIM 的 P(...) 默认输出是相位 ϕ\phi，单位为 rad（弧度），不是 ϕ/(2π)\phi/(2\pi)，也不是“SFQ 个数”。旧脚本 scripts/sfq_metrics.py 直接把原始弧度标成了 SFQ，同时把超过阈值的采样间隔数叫作 fast_events。这造成了两层错误：

  1. 所有相位派生数值放大了 2π2\pi 倍；
  2. 一个持续多个采样点的物理脉冲会被重复计数，fast_events 不是事件数。

正确换算是：

NΦ0=Δϕrad2π=1Φ0∫V(t)dt N_{\Phi_0}=\frac{\Delta\phi_{\mathrm{rad}}}{2\pi} =\frac{1}{\Phi_0}\int V(t)\,dt

这里得到的是同一个 JJ 的净相位绕转数，右侧的 V(t)V(t) 也必须是这个 JJ 同一对端点之间的电压。它等价于该结电压面积的 Φ0\Phi_0 倍数，但不等于闭合环的 fluxoid 数或材料中的微观涡旋数。

这项错误直接推翻了旧文档中的几项核心判断：

  • 旧文档依据 P(JM1)≈±5.9 直接推出“约 ±6\pm6 个涡旋”的证据链已被推翻；正确换算只能说 JM1 的稳定相位约为 ±0.94\pm0.94 圈。这与论文的单磁通子双稳态模型相容，但不能只凭一个结的相位断言完整环的 fluxoid 数，因而本次审计也没有独立证明真实 fluxoid 一定不是 6。
  • 基线 BQ 输入结 BJs 不是“前进 6.27 个量子”，而是约前进 0.998 圈。
  • 标准 DCSFQ 的 300 µA 响应不是“7–8 次爆发”；减去零输入的偏置启动背景后，B1、B2、B3 各自恰好改变约一圈。
  • BQ v4 的下游 JTL 不是收到“38 个失控事件”；38 rad 约等于六圈，而测试恰好有六个输入周期。在当前周期 PULSE、偏置、负载和步长下，110–150 µA 的下游相位平台表现与约 1:1 传播相容；完整 SFQ Gate 尚未通过。

因此，2026-08-06 旧版 HANDOVER.md 中所谓“冻结口径”、BQ 已被系统排除、以及直接执行 Phase 1 的计划都不能继续原样使用。当前的 docs/HANDOVER.md 已按本次审计重写。当前合理阶段是Phase −1：先修复测量定义和重建基线。

第一篇：先补齐电路与超导基础

1. 电流、电压和功率不是同一件事

如果把电路类比成水路：

  • 电流 II：单位时间通过多少电荷，类似流量，单位 A；
  • 电压 VV：推动电荷运动的能量差，类似压差，单位 V；
  • 电阻 RR：对运动的耗散性阻碍，满足 V=IRV=IR；
  • 功率 P=VIP=VI：单位时间转移或耗散的能量。

“某节点有 68 µA”不等于“有一个 SFQ”。SFQ 的定义涉及电压对时间的积分，而 68 µA 是某条支路在某个负载和某个时刻的电流。整个项目的接口困难，本质上就是不能把这两个量直接画等号。

1.1 地、节点和支路

网表里的 0 是参考节点（ground）。节点电压都相对它定义；支路电流有方向，交换元件两端会改变输出符号。负号通常表示“实际方向与网表定义的正方向相反”，不等于仿真错误。

【基本定律】两个守恒关系贯穿所有电路：

KCL：节点流入电流之和=流出电流之和 \text{KCL：节点流入电流之和}=\text{流出电流之和}

KVL：沿闭合回路的电压升降代数和=0 \text{KVL：沿闭合回路的电压升降代数和}=0

它们解释了为什么输入电流会分流、为什么增加负载会改变 BVM 的输出、以及为什么不能只用电流源标称幅度判断某个 JJ 是否达到临界电流。

2. 电阻、电容和电感在瞬态里做什么

元件 关系 直觉 在项目中的作用
电阻 V=IRV=IR 把电能耗散成热 限流、建立偏置、抑制振铃
电容 I=CdV/dtI=C\,dV/dt 电压不能无代价瞬变 JJ 的“惯性”，影响开关和振铃
电感 V=LdI/dtV=L\,dI/dt 电流不能无代价瞬变 保存磁场能量、耦合与延迟、形成环流

高中稳态电路里常把电感看成短路、电容看成开路；在本项目的皮秒瞬态中，这种简化通常不够。电感的频域阻抗为 jωLj\omega L，电容为 1/(jωC)1/(j\omega C)，但 SFQ 是宽带瞬态，不应只挑一个“代表频率”就把完整非线性网络当成两个线性阻抗分流。

2.1 偏置为什么必要

偏置是在没有输入事件时先把结放到某个工作点。一个典型 RSFQ 结会被偏置到临界电流以下；输入只需补足剩余裕度便可触发。触发后的电流重新分配，结应回到零电压态。

这并不意味着“70% IcI_c”是所有电路的普遍常数。它是许多标准单元的设计选择，真正可用范围要由拓扑、阻尼、工艺参数和负载共同验证。

2.2 源和负载为什么不能分开看

理想电流源会强制指定电流；真实 BVM 输出不是理想源。项目的负载扫描得到一个局部经验拟合：

Iload≈VthZth+Rload I_{\mathrm{load}}\approx\frac{V_{\mathrm{th}}}{Z_{\mathrm{th}}+R_{\mathrm{load}}}

其中峰值拟合约为 Zth∼40ΩZ_{\mathrm{th}}\sim40\ \Omega、Vth∼4mVV_{\mathrm{th}}\sim4\ \mathrm{mV}。【项目实测】这只描述已测波形和负载范围中的有效峰值关系，不是频率无关、幅度无关的固有电阻。BVM 是非线性瞬态源，换拓扑或时间窗后，这两个拟合量可能改变。

3. 超导：需要的不是“零电阻”一句话

【基本定律】在温度、磁场和电流都处于材料允许范围内时，超导态具有宏观相干的复序参量，可写成：

Ψ=|Ψ|eiθ \Psi=|\Psi|e^{i\theta}

这里的 θ\theta 是相位。超导体的直流电阻消失只是现象之一；本项目真正使用的是宏观相位、Josephson 效应和闭合环的量子化约束。

需要避免三个常见误解：

  • Φ0\Phi_0 是磁通量子，不是“最小磁场单位”。磁场 BB 的单位是 T，磁通 Φ=∫BdA\Phi=\int B\,dA 的单位才是 Wb。
  • 不是任意空间里的磁通或磁场都只能取 nΦ0n\Phi_0。严格约束涉及闭合超导路径中的相位绕数/fluxoid 条件。
  • “非易失”在 BVM 论文中指超导状态持续维持时无需保持偏置保存环流，不代表升温到正常态或室温断电后仍保存。

磁通量子为：

Φ0=h2e≈2.067833848×10−15Wb≈2.0678mV⋅ps \Phi_0=\frac{h}{2e} \approx2.067833848\times10^{-15}\ \mathrm{Wb} \approx2.0678\ \mathrm{mV\cdot ps}

含 JJ 的闭合环中，相位差、电感电流造成的磁通和外加磁通共同满足量子化条件。示意写法是：

∑jϕj+2πΦ0Φloop=2πn \sum_j\phi_j+\frac{2\pi}{\Phi_0}\Phi_{\mathrm{loop}}=2\pi n

具体符号取决于环方向和定义。这个公式也说明：单独读取一个 JJ 的相位，并不足以直接得到完整环的整数 nn。

4. Josephson 结：不是“超过阈值就变成普通电阻”

Josephson 结是两个超导电极之间的弱连接。两个核心关系是：

Is=Icsin⁡ϕ I_s=I_c\sin\phi

V=Φ02πdϕdt V=\frac{\Phi_0}{2\pi}\frac{d\phi}{dt}

【基本定律】第一式说明零电压超电流依赖规范不变相位差；第二式说明电压与相位转动速度成正比。

由第二式积分可得：

Δϕ=2π⇔∫V(t)dt=Φ0 \Delta\phi=2\pi \quad\Longleftrightarrow\quad \int V(t)\,dt=\Phi_0

这才是 SFQ 测量的核心。

“电流小于 IcI_c 时 JJ 像不存在，大于 IcI_c 时突然成为电阻”只能作为第一遍直觉。更准确地说：

  • 零电压态仍有相位依赖的 Josephson 电感；
  • 支路电流由整个网络决定，不等于输入源标称值；
  • 达到动力学失稳后，相位可能越过一个或多个势阱；
  • 是否停住、回摆或持续运行由电容、耗散、偏置和外部网络共同决定。

4.1 RCSJ 模型：一个带惯性和摩擦的非线性系统

常用 RCSJ 近似把结写成理想 Josephson 元件、电阻和电容的并联：

I=Icsin⁡ϕ+VR+CdVdt I=I_c\sin\phi+\frac{V}{R}+C\frac{dV}{dt}

代入 Josephson 电压关系：

Φ0C2πϕ̈+Φ02πRϕ̇+Icsin⁡ϕ=I \frac{\Phi_0C}{2\pi}\ddot\phi +\frac{\Phi_0}{2\pi R}\dot\phi +I_c\sin\phi=I

可以把相位想成周期势阱里的小球：

  • CC 提供惯性；
  • RR 提供耗散；
  • Icsin⁡ϕI_c\sin\phi 形成周期恢复力；
  • 外部电流让势能“倾斜”。

McCumber 参数常写为：

βc=2πIcR2CΦ0 \beta_c=\frac{2\pi I_cR^2C}{\Phi_0}

大 βc\beta_c 通常意味着更欠阻尼和更强滞回，但应使用工作状态下的有效阻尼。项目的 jjmit 使用 RTYPE=1，有 r0、rn 和能隙相关的分段电导；外部 RB/LRB 和完整拓扑也会改变阻尼。因此“用 rn 算出约 5.4，所以所有结必然失控”是不充分的。

4.2 Josephson 电感的正确用法

零相位附近的小信号近似是：

LJ(0)=Φ02πIc L_J(0)=\frac{\Phi_0}{2\pi I_c}

更一般地：

LJ(ϕ0)=Φ02πIccos⁡ϕ0 L_J(\phi_0)=\frac{\Phi_0}{2\pi I_c\cos\phi_0}

降低 IcI_c 会在同一工作相位下增大 LJL_J，这是可靠的局部趋势；但它不是证明“任何低 IcI_c 接口都数学无解”的普遍定理。旧文档所谓 BQ 的“LJL_J 矛盾”只能保留为对某些已测拓扑的设计风险。

4.3 area 参数为什么能缩放结

项目模型 circuits/models/jjmit.cir 的基准参数是：

.model jjmit jj(RTYPE=1, VG=2.8m, CAP=0.07p,
+ r0=160, rn=16, icrit=0.1m)

JoSIM 对实例 area=A 的缩放是：【源码事实，src/JJ.cpp】

  • Ic∝AI_c\propto A；
  • C∝AC\propto A；
  • Rn,R0∝1/AR_n,R_0\propto1/A。

所以把 area=2.25 改成 0.8 会把基准临界电流从 225 µA 改成 80 µA，同时还改变电容、电阻和动态。它不是只移动一个理想比较器阈值。

5. SFQ：量子化的是面积，不是峰值、宽度或能量

SFQ 事件的定义性关系是：

∫Vdt=±Φ0 \int Vdt=\pm\Phi_0

因此可以说“一次净 2π2\pi 相位滑移具有一个磁通量子的电压面积”。不能据此说：

  • 所有 SFQ 峰值相同；
  • 所有 SFQ 都严格宽 2 ps；
  • 每个事件的总能量完全相同；
  • 任意结的一圈相位变化都表示环里永久增加一个涡旋。

若粗略把脉冲当成 2 ps 矩形，平均电压约为 1.03 mV；真实波形由偏置、IcRI_cR、电容、阻尼和负载决定。能量尺度常与 IbΦ0I_b\Phi_0 有关，也会随工作点变化。量子化的是相位绕转和电压时间积分，不是总耗散能量。

5.1 JTL 为什么能够传输数字事件

Josephson Transmission Line（JTL）不是无源导线，而是带偏置和阻尼的一串 JJ：

  1. 输入事件触发第一级；
  2. 电感中的电流重分配推动下一级；
  3. 每一级利用本地偏置重新产生约一圈相位事件。

所以严谨说法是：“JTL 在设计裕度内再生并传播量子化事件。”波形细节仍会改变，负载、偏置或时序不合适时也会丢失、多触发或无法传播。ColdFlux 手册 PDF p17 §2.1.1 将 JTL 描述为重新建立并传播 SFQ；PDF p14 明确要求 DUT 成功驱动其输出负载，才算功能验证。【论文表述】

6.1 MNA/MNPA 的直觉

每个时间步，JoSIM 都在解一个稀疏方程组：

Anxn=bn A_nx_n=b_n

  • xnx_n：节点相位/电压、某些支路电流和辅助未知量；
  • AnA_n：电路拓扑和当前线性化电导；
  • bnb_n：源、历史项和 JJ 的非线性电流贡献。

电阻、电感、电容、JJ、源和受控源分别把小块系数“盖章”到大矩阵里，这就是 stamping。子电路必须先展平，因为求解器最终只看一个大网络。

6.2 为什么要离散时间

电感、电容和 JJ 方程含导数，计算机只能在 t0,t1,…t_0,t_1,\dots 上求近似。当前 JoSIM 使用二阶 Gear/BDF2 系数来近似导数。BDF2 往往比简单显式方法更适合刚性电路，但仍不是“步长无关”。

项目常用 .tran 0.1p ...；这是请求的名义步长，JoSIM 在传输线约束或 JJ 相位预测过大等情况下可以缩小步长并重建仿真，不应把它理解为永远严格固定 0.1 ps。任何关键结论仍应用 0.05 ps、0.025 ps 等更细的请求步长检查收敛，而不能只靠同一设置重复三次。

6.3 KLU 做什么

电路矩阵大而稀疏；本次冻结二进制使用 KLU 做稀疏 LU 分解，比把矩阵当成普通稠密数组高效。JoSIM 源码也保留了 SuperLU 条件分支，所以这不是所有构建唯一可能的后端。线性求解器解决的是每步的代数方程，不替我们判断电路设计是否物理合理。

8. P()、V() 和 I() 应如何解释

  • P(B...)：默认 phase 模式下的相位差，单位 rad；
  • V(node) 或相应电压 trace：单位 V；
  • I(element)：按网表端点定义方向的支路电流，单位 A。

源码证据非常直接：src/Output.cpp 的 phase 分支输出内部相位差，没有除以 2π2\pi；scripts/josim-plot2.py 也默认标为 Phase (rad)，只有 -j 2pi 才做归一化。JoSIM 自带 JTL 示例输入两个事件后，相位约为 13 rad，接近 4π4\pi，进一步验证这一点。

8.1 为什么“从 t=0 到末尾”常常数错

偏置源在仿真开始时建立工作点，本身会造成非整数静态相位偏移。例如标准 DCSFQ 零输入结束时 B3 约为 0.809 rad。300 µA 运行结束时约为 7.093 rad；直接除以 2π2\pi 得 1.129 圈仍混入启动背景。

同参数的零输入对照相减后：

7.092557−0.809372=6.283185rad≈2π 7.092557-0.809372=6.283185\ \mathrm{rad}\approx2\pi

所以输入诱导响应才是约一圈。更好的做法是比较事件前后的稳定窗口，或减去完全匹配的零输入控制。

8.2 一个严谨的“收到一个 SFQ”判据

至少应同时满足：

  1. 明确原始相位单位为 rad；
  2. 在事件前后稳定窗计算 Δϕ/(2π)≈±1\Delta\phi/(2\pi)\approx\pm1；
  3. 对产生该 P(JJ) 的同一个 JJ、同一对端点检查 ∫VJJdt/Φ0≈±1\int V_{JJ}dt/\Phi_0\approx\pm1；节点对地的 V(OUT_Q) 不能直接拿来核对 BJs 相位；
  4. 把连续的快速采样点聚成一个事件，不能逐点计数；
  5. 检查事件之间存在稳定平台，而不是持续电压态；
  6. 检查下游 JTL/load 也发生相应一圈变化；
  7. 读 0 时不得产生事件，重复读时不得多出或丢失；
  8. 用零输入对照和更细时间步复核。

第三篇：项目中每个模块为什么存在

9. BVM：保存状态并给出读电流

主要论文是 arti/Karamuftuoglu_2025_Supercond._Sci._Technol._38_015020.pdf。作者在 PDF p4 §2.1/Fig. 1 给出双环概念，p5 Fig. 2 给出电路参数，p6 §§2.3–2.4 描述写读，p7 §2.5 讨论存储条件和鲁棒性。论文把 BVM 描述为两个相连的 SQUID 环：【论文表述】

  • Storage Loop：保存两个相反的环流/磁通子状态；
  • Readout Loop：在读使能到来时把状态转成 SL 输出电流；
  • WL、BL：共同选择并写入；
  • SE：读使能；
  • SL：读出端。

论文模型用 M=−1M=-1 和 M=+1M=+1 表示两种状态。JoSIM 不解析材料内部的涡旋芯，所以本文更谨慎地称它们为“两个双稳态环流/磁通子状态”。

9.1 仓库网表的结构

circuits/bvm/bvm_cell.cir 中：

  • WL、BL 经电阻和小电感汇入写入节点；
  • JM1、JM2 与 LM1/LM2/LM3/LPM 构成存储相关闭环；
  • JS1、JS2、RS 和 LS 支路构成读出环；
  • RSL/LSL 构成 SL 输出路径。

论文明确给出的设计意图包括：【论文表述】

  • WL 与 BL 的半选机制：单独一条线不应写入，两者叠加才越过写入条件；
  • JM1 是主要写入开关；
  • JM2 提高稳定与裕度；
  • 读环把保存状态和输出过程分开；
  • SE 不宜强到破坏存储状态；
  • 论文使用 IcL>Φ0I_cL>\Phi_0 作为存储能力的粗略设计准则。

最后一条不是完整充分条件。实际双稳态性由整个非线性环、总电感、相位约束和工作点共同决定。

9.2 当前数据对 BVM 说明了什么

【项目实测】经正确单位换算：

  • WL=100 µA 的测试中，W1 稳定相位约 +5.891 rad = +0.938 圈；
  • W0 稳定相位约 −5.886 rad = −0.937 圈；
  • 两态切换约 −11.832 rad = −1.883 圈；
  • WL=80 µA 未写入，WL=100/120 µA 能进入近一圈的稳定状态；
  • 100 µA 读操作后的相位漂移约为 0.004–0.009 圈；
  • 120 µA 的 R0 测试会把负态擦回接近零；
  • 两轮读电流峰值可重复，正负状态的输出明显不同。

这些数据支持“存在稳定、可区分、100 µA 读近似非破坏的两个状态”。它们推翻了旧文档用单个 JM1 原始 rad 值证明“±6\pm6 多涡旋”和“不存在单涡旋工作点”的论证；完整环 fluxoid 数仍待计算。

【待验证】严格声称环内 fluxoid 数为 ±1\pm1，还应把环中各 JJ 相位、外加磁通和 LILI 项按统一方向代入完整量子化条件；不能把 P(JM1) 一列直接当作环的 vortex 计数器。

9.3 为什么输出随负载变化

P0.0 负载扫描得到：【项目实测】

  • 峰值电流约 43.9–97.8 µA；
  • FWHM 约 6.8–11.2 ps；
  • BQ 基线负载下约 68.4 µA；
  • 读 0 稳态电流很小，但开关边沿可出现数十微安瞬态。

原因的确定部分是 KCL 和动态阻抗：负载改变输出节点条件，电流会在 BVM 内部支路与负载之间重新分配。【解释性推断】具体正负回铃来自哪些读环模态，需要通过去元件/改阻尼对照或小信号模态分析才能唯一归因，不能只凭波形形状说“就是某个 LC”。

10. BQ：把累积磁通变化量化的候选单元

原始 BQ 来源于 arti/Hybrid synaptic structure for spiking.pdf。论文 PDF p5 Fig. 4 把它描述为类似数字 SQUID 的 Buffer/Quantizer：汇总正负磁通变化并给出量化脉冲；PDF p6 Fig. 7 明确把相位除以 2π2\pi 后才数脉冲。【论文表述】

需要区分名称：2024 Hybrid Synaptic 论文使用 BQ（Buffer/Quantizer）；2025 BVM/MVM 论文使用 QB（Quantizer Buffer），声称其阈值适配单个 BVM 输出，但没有公开完整参数。仓库 bq_cell.cir 是从 2024 BQ 拓扑缩放并增加分流的项目派生版，不能默认等同于 2025 论文仿真中的 QB。

仓库的 circuits/qb/bq_cell.cir 不是论文原始参数，而是为 BVM 电流量级缩放并增加分流后的派生版本。其核心支路包括：

  • BJs：输入感测结；
  • BJL1/RJ1：回流/偏置相关支路；
  • BJL2/RJ2：输出支路；
  • RB 与 L1/L2：建立偏置和动态耦合。

只看“BJs 没有一个显式并联外部 shunt”不能证明它完全无阻尼或无偏置；电流可经完整回路建立，内部 r0/rn 也参与耗散。要确认因果，必须做只改变一个网络的受控实验。

10.1 直接 BVM→BQ 基线真正发生了什么

基线原始 CSV 的净相位为：

位置 原始相位变化 正确归一化 可下的结论
BVM JM1 −5.909806 rad −0.940575 圈 与切换到另一稳定相位平台相容
BQ BJs +6.272743 rad +0.998338 圈 净绕转接近 +1；完整轨迹与一次净变化相容
BJL1 +0.443319 rad +0.070556 圈 净值远小于一圈；完整轨迹未跨完整 2π2\pi

同时 V(OUT_Q) 峰值约为 157 µV。但该基线网表的 OUT_Q 只接了 10 Ω 电阻负载，没有下游 JTL；因此它能检查 BQ 输出支路，不能回答“JTL 是否接收”。【网表事实/项目实测】

所以最稳妥的结论是：

BJs 的稳定窗轨迹与约一次净 2π2\pi 相位变化相容；BJL1/BJL2 的完整轨迹没有相应完整绕转，因此当前基线没有证明 BQ 完成可用的 SFQ 转换。该网表未接 JTL，传播能力并未被测试。仅凭全窗口净值本身不能证明事件数，也不能排除正反滑移互相抵消；还需稳定窗、完整轨迹和同一 JJ 两端电压面积共同判定。

旧文档把 fast_events=0 解释为“不是离散翻转”，也不可靠：BJs 的最大单步变化约 0.291 rad，恰好低于脚本任意设置的 0.3 rad/sample；这只说明波形在当前采样率下没有跨过该导数阈值，不能决定它是不是一个积分为 Φ0\Phi_0 的事件。

10.2 BQ v4 不是被排除，而是重新成为候选

v4 同时改了 L0、BJL1/BJL2 面积以及 RJ1/RJ2，所以单次 v3/v4 对照无法隔离某一个根因。

更重要的是，test/final/qb/test_bq_v4_sweep.cir 在 300 ps 内输入六个周期脉冲。正确归一化后：【项目实测】

理想电流脉冲幅度 下游 JTL 行为
70、90 µA 已测点只有启动偏移，没有逐周期累积
110、130、150 µA 以首脉冲前稳定点为参考，六个输入对应下游约六个 2π2\pi 平台增量，与约 1:1 相容

110 µA 时，以 9.9 ps 的首脉冲前点为参考，JTL B1 在 49.9、99.9、…、299.9 ps 约为 1.0015、2.0015、…、6.0017 圈。BJL1、BJL2 和 JTL B2 也显示逐周期近整数递增。这是对原始 CSV 的只读审计计算；稳定窗尚待 Phase −1 工具化定义。

这反证了旧结论“v4 输出级死亡、JTL 收到 38 个失控事件”。正确状态是：

  • 在当前理想周期 PULSE 测试台的离散扫点中，90 µA 未见逐周期累积，110 µA 已出现与量子化下游响应相容的平台；在尚未验证单调性且未细扫前，不把边界称为已确定阈值；
  • 110–150 µA 时下游相位平台与每输入一个事件相容，但单脉冲、电压面积、事件聚类和步长收敛尚未完成；
  • 在产生下游平台的 110–150 µA 已测点，输入 BJs 本身每周期净运行约 18–22 圈（完整 70–150 µA 扫描范围为约 16–22 圈）；【项目实测】由此产生的耗散和鲁棒性风险仍是【解释性推断】，需要进一步测量；
  • 68.4 µA 是旧 BQ-v2 输入加载基线下的 BVM 峰值；BQ v4 会改变所见输入阻抗，所以真实 v4 级联时的电流波形尚不知，不能把 68.4 µA 当成与负载无关的固定源幅度。

所以“BQ v4 已解决接口”和“BQ 拓扑已系统排除”都不成立。它现在是一个需要用单次真实波形、细阈值和鲁棒性重新测试的候选。

11. DCSFQ 与 DCSFQ_BVM：另一个接口候选

ColdFlux 手册 PDF p123 §2.4.1 对标准 DCSFQ 的明确描述是“输入电压脉冲转换成 SFQ 脉冲”；p125 Listing 2.35 给出网表，p126 Fig. 2.74 给出输出与负载相位仿真。它不是“任意慢 DC 电流 ADC”。本项目把它改造成 BVM 电流接口，是新的用法，必须独立验证。【论文表述】

11.1 标准 DCSFQ 为什么有三个结

circuits/standard/DCSFQ.cir 包含 B1、B2、B3、输入耦合电感、两个偏置源，以及每个结的 RB+LRB 分流支路。可以按功能理解为：

  • B1/B2 与输入网络共同完成敏感和状态转移；
  • B3 是标准量级的输出结；
  • 偏置把结放到可触发但静态稳定的工作点；
  • 外部分流网络提供频率相关的耗散和动态整形。

最后一点不应简化为“RB 的数值恰好证明整个非线性电路处于临界阻尼”。RB 消耗能量是确定的；LRB、内部分段电阻和其他结共同决定瞬态，精确阻尼状态仍需分析。

11.2 项目到底改了什么

circuits/interface/DCSFQ_BVM.cir 相对标准单元的主要功能变化只有：

  • B1/B2：area 2.25 → 0.8，即 225 µA → 80 µA；
  • IB1：275 µA → 100 µA；
  • 与面积相关的 RB/LRB 随公式缩放；
  • B3、IB2 和标准输出级保持不变。

设计意图是降低输入级所需信号，同时保留标准输出驱动力。由于 area 同时改变 Ic,C,RI_c,C,R，这仍是一种动力学重设计，不是简单改比较阈值。

11.3 Phase 0 数据经纠正后说了什么

在当前标准 DCSFQ 测试台和指定 bump 波形下：【项目实测】

  • 0–150 µA 范围内的已测点没有输入诱导的完整 2π2\pi 内部响应；
  • 300 µA 与零输入对照相减后，B1 为 −1 圈、B2/B3 各为 +1 圈；
  • 短 bump 和长 sustained 的最终状态逐位相同，保持平台没有继续累积。

这支持“该测试拓扑在 300 µA 下给出单量子净相位响应；保持时间没有造成持续泵浦”。它尚未证明已经生成合格 SFQ 脉冲：还需对同一 JJ 的端电压积分，并补下游 JTL、单次输入和步长验证。当前离散扫点中，150 µA 未见完整内部绕转，300 µA 出现净绕转；在尚未验证响应对幅度单调且未细扫前，只能说转变边界未定位，不能把 (150, 300] µA 写成已确定的输出或 JTL 阈值。

缩放版 DCSFQ_BVM：【项目实测】

  • 68.4 µA 测试输入没有观察到完整输出相位绕转；
  • 输入增量进入 L3/结支路的比例约 0.285；
  • 因而当前起点参数未完成 BVM 电流到 SFQ 的转换。

旧计划把目标阈值定为 45–55 µA，理由之一是误以为 300 µA 已发生 7–8 次多滑移。这个依据已经失效；阈值应由正确事件定义下的扫描重新确定。

11.4 “极性”怎样才算真正测试

交换子电路输入端 a 和输出端 q 不是反转极性，而是倒用一个有方向的电路。正确的极性实验应：

  • 反转输入源电流方向；或
  • 构建拓扑明确、端口方向有文档的 signed-input 变体；
  • 同时保持其余参数、偏置和负载不变。

12. ColdFlux 标准单元、JTL 与测试成熟度

circuits/standard/ 中有 35 个 ColdFlux 单元网表。仓库还存在 JTL、SPLIT、MERGE、DFF、XOR、AND2、NDRO、NOT 的人工测试网表。

但当前 test/CMakeLists.txt 只注册上游 23 项 JoSIM 测试，研究单元测试没有程序化接入 CTest；一些“验证通过”只是人工看波形，AND2 也未覆盖完整四行真值表。因此准确说法是：

标准库已导入，若干代表单元有人工/单点测试，但尚未形成带数值断言、完整真值表和裕度扫描的自动回归库。

13. T1：处理已经数字化的脉冲

arti/2507.04648v1.pdf PDF p3 §2.3、p4 Fig. 3 把 T1 描述为具有同步 sum 和异步 carry 的 SFQ 计数/加法单元，并说明每对输入产生 carry、奇数余量在 clock 后产生 sum。【论文表述】据此，若时钟前收到 nn 个输入脉冲，本文可作如下简洁代数归纳：【本文推导】

C=⌊n2⌋,S=nmod⁡2 C=\left\lfloor\frac n2\right\rfloor, \qquad S=n\bmod2

每对脉冲可异步产生一个 carry；奇数余量在时钟到来时产生 sum。对最多三个输入，这与全加器的奇偶和/多数进位相容；对更多输入，它还可连续产生多个 carry。仓库没有该论文引用的 DAC 2024 原始 T1 全文，因此任意 nn 的边界、恢复和全部时序条件仍未从原始 T1 来源独立核验。

仓库 circuits/t1/t1_cell.cir 已转录 11 个 JJ 的七端口网表，并对论文图中的一个重复编号采用了一种实现映射假设；仓库尚没有独立证据证明该映射唯一或正确。当前也缺少完整、可自动裁决的脉冲计数和时序验证，所以只能说“网表已转录、局部测试存在，完整功能待验证”。

系统分工必须写成：

BVM 电流 → BQ/DCSFQ_BVM 量化 → JTL 再生/传输 → T1 计数和进位

不能让 T1 直接承担慢模拟电流量化；论文也不是这样描述的。

15. 哪些实验结论仍然成立

相位缩放不会影响以下直接测量：

  • BVM 负载扫描中的电流峰值和 FWHM；
  • BQ 基线的电压峰值；
  • DCSFQ_BVM 的 0.285 增量分流；
  • P2 的读电流对比、重复性和 120 µA R0 擦除现象；
  • 固定输入下 CSV 的字节级哈希一致。

经原始相位重算后仍可保留：

  • 当前直接 BVM→BQ 基线中，BJL1/BJL2 没有完整相位绕转，尚未证明 BQ 完成有效量化；该网表未接 JTL，不能判定下游传播；
  • BVM 在已测条件下有两个接近正负一圈的稳定相位态；
  • 标准 DCSFQ 在当前已测 bump 点中，150 µA 未见完整内部绕转，300 µA 相对零输入控制出现约一圈；实际边界、合格输出和 JTL 接收尚未定位；
  • DCSFQ_BVM 起点参数在 68.4 µA 测试输入下未见完整输出；
  • BQ v4 在 70/90 µA 已测点没有逐周期下游响应；在 110/130/150 µA 的当前理想周期测试下，下游相位平台与约 1:1 传播相容。

17. 哪些解释仍只是候选假设

以下说法有物理合理性，但当前不能当成已证明根因：

  • BQ 基线失败主要由 BJs 欠阻尼造成；
  • BQ 的理想电流源一定充当不可控“通量泵”；
  • BQ 的峰值电流小于某个 JJ 的 IcI_c，所以必然不能驱动 JTL；
  • RB+LRB 恰好把整个 ColdFlux 非线性单元调到临界阻尼；
  • BVM 读出回铃由某一个特定 LC 模态主导；
  • DCSFQ 的平台不累积完全由 L2 的“边沿耦合”造成；
  • 互感 K 元件只适合 MHz–GHz，不适合皮秒事件；
  • 所有低 IcI_c BQ 设计都被 LJL_J 数学上排除。

正确做法是为这些假设设计单变量对照，而不是从一组综合改动中反推唯一因果。

18. 确定性、准确性和鲁棒性是三件不同的事

  • 确定性：相同输入重复运行得到相同字节；项目已有若干哈希证据。
  • 数值准确性：步长变细后关键量收敛；当前研究实验普遍缺少系统检查。
  • 物理有效性：模型、寄生参数、激励和判据足以代表目标硬件；仍需要论文参数核对、裕度和最终硬件证据。

哈希只证明第一项。一个单位写错的分析也可以百分之百可重复。

第五篇：测量管线为什么失效，以及怎样修

19. sfq_metrics.py 的两个独立问题

问题 A：单位错了 2π2\pi

旧脚本直接计算：

net_delta = p[-1] - p[0]

但 p 是 rad。正确的归一化量应除以 2π2\pi。max_excursion、total_variation、max_dPdt 的标签和单位也必须相应重定义。

问题 B：采样点数不是事件数

旧脚本把满足：

abs(p[i] - p[i-1]) > 0.3

的相邻样本逐个累加。一个时间局域的物理事件可以跨越多个采样间隔，因而被这种方法重复计数。把阈值简单改成 0.3×2π 也不解决问题：真实事件可能在每个 0.1 ps 步长内都小于该阈值。

导数阈值可以用来定位“候选活动区”，但之后必须聚类、积分和检查平台。

20. 新指标应该怎样定义

建议每次运行生成以下互不混淆的量：

指标 定义 用途
phase_delta_rad 稳定窗相位差 保留原始单位
phase_delta_phi0 phase_delta_rad/(2π) 归一化净绕转
voltage_area_phi0 对同一 JJ 两端计算 ∫V_JJ dt/Φ0 与该 JJ 的相位交叉校验
activity_clusters 连续导数超阈值样本聚类 候选事件区，不直接等同 SFQ
settling_error 事件后平台偏离整数的量 判断是否停稳
reverse_excursion 反向显著回摆 检测 backfire/ringing
downstream_delta JTL 各级逐事件平台变化 系统级接收结果

每个激励都应有明确事件窗口、事件前参考窗、事件后稳定窗。若有偏置启动，使用相同参数的零输入对照，或在启动完成后再取参考。

21. 修复脚本前后的最小回归测试

测量工具至少要通过：

  1. 合成 0 → 2π 相位台阶，必须得到 1 圈而不是 6.283；
  2. 合成同一台阶跨 10 个采样点，事件聚类仍只得到 1；
  3. JoSIM 官方两脉冲 JTL 示例，扣除启动偏移后得到 2 个下游事件；
  4. 标准 DCSFQ 300 µA 减零输入对照得到 B1/B2/B3 的 −1/+1/+1；
  5. BQ v4 110 µA 六周期测试得到下游约六个整数相位平台增量，而不是约 38 个事件；
  6. 同一个 JJ 的相位法与其同端电压积分法在数值容差内一致；
  7. 0.1、0.05、0.025 ps 的事件结论一致，误差随步长缩小。

只有这些通过后，才应在各实验目录的 data/metrics_v2/ 中生成新版 JSON、改写 BASELINE/P0/P2 和解冻 Phase 1。旧 JSON 保留为审计记录，不覆盖。

21.1 Gate 的数值容差必须先校准、后冻结

“约等于一圈”不是可执行的验收规格，但本次审计也不应在没有校准的情况下凭空写出百分比。在任何 BQ v4 或 DCSFQ_BVM 候选参数测试之前，应新建并冻结 METRIC_SPEC_V2.md，用零输入噪声、官方 JTL 例子、DCSFQ 对照和步长收敛数据校准至少下列容差：

  • 事件前后稳定窗的精确边界，以及整数相位平台残差；
  • 同一 JJ、同一对端点、同一方向和同一时间窗下，phase_delta_phi0 与 voltage_area_phi0 的允许误差；
  • BVM 读取前后允许的状态漂移；
  • 0.1/0.05/0.025 ps 间相位、电压面积和事件结论的允许差异；
  • 输入幅度、时序抖动、偏置和负载扫描所需的通过范围。

容差的来源、校准网表、JoSIM 版本和选定理由都必须写入该规格；规格冻结后再跑候选设计，防止看到结果后移动 Gate。

最终结论

本项目的科学问题是成立的：BVM 给出的状态相关电流不能被默认当成 RSFQ 数字事件，接口必须在真实源阻抗、波形、偏置和负载下完成量化与再生。BVM 的两个 JM1 相位平台和状态相关读电流已有可重复的电路级仿真证据；完整环 fluxoid 数、参数裕度和硬件行为尚未验证。直接 BVM→当前 BQ 基线未证明输出支路完成量化，且网表未接 JTL；BQ v4 在当前理想高幅周期电流下显示与 1:1 传播相容的下游相位平台，但尚未通过完整 SFQ Gate；DCSFQ_BVM 仍是尚未完成真实级联验证的候选。

当前第一优先级不是继续扫参数，而是修复相位单位和事件定义、用校准数据事先冻结数值容差并重建基线，然后用同一套可审计判据公平比较两条接口路线。只有下游 JTL 在读 1 时恰好接收一次、读 0 时不接收、BVM 状态不被破坏，并通过步长与参数裕度检查，才可以说接口完成。
