# Mechanism diagnostic review boundary

Scientific interpretation is `NOT_PERFORMED`.

`MECHANISM_REVIEW.md` and `mechanism_metrics.json` contain raw-oriented
measurements, actual-grid arithmetic, phase navigation and descriptive
closed-loop/replay differences. They do not define an SFQ/event counter and do
not decide whether N3 has a fourth response in the scientific sense.

The passive waveform is a source-loading counterfactual. The replay is ideal
current forcing and is not a circuit-equivalent source reconstruction. Any
comparison is bounded to the declared 0–200 ps stored grid, models, load,
protocol and solver.
