## 1. 基本量与单位

JoSIM phase 模式的 `P(J)` 原始输出是相位 \(\phi\)，单位 rad。始终先保留：

\[
\Delta\phi_{\rm rad}=\phi_{\rm post}-\phi_{\rm pre}
\]

再派生净相位圈数：

\[
N_{\rm turn}=\frac{\Delta\phi_{\rm rad}}{2\pi}
\]

`P(J)=6.28 rad` 是一个绝对角度；只有声明参考窗后的 `ΔP≈6.28 rad` 才与约一圈净绕转相容。不要把 raw rad 命名为 `sfq`。

一个 JJ 的相位圈数不等于闭合 BVM 环的 fluxoid 数。完整环状态需要相位、磁通和环量子化约束的联合计算。

## 2. 时间窗和控制

使用由实验计划预先声明的多样本稳定窗：

- `pre_window`：偏置启动完成后的参考平台；
- `activity_window`：允许因果响应出现的区间；
- `post_window`：振铃结束后的结果平台；
- `read_state_window`：判断存储状态是否被破坏。

报告稳定窗的代表值和窗内波动。若启动背景不能由 pre 窗消除，使用除输入外完全匹配的零输入控制。不要直接使用 `t=0` 和最后一个采样点，除非规范明确证明二者是稳定参考。

## 3. 活动、本地事件与净值

导数或相邻采样差阈值只能定位 `activity_clusters`。一个物理脉冲可能跨多个采样点；多个过阈值样本不是多个事件。

区分：

- `net change`：最终圈数变化；
- `forward/reverse excursion`：轨迹中的正反活动；
- `activity cluster`：快速变化候选区；
- `local event`：稳定窗、整数相位和同 JJ 电压面积共同支持的事件。

例如先前进两圈再后退一圈，净值为一圈，但完整轨迹并非简单的一次正向事件。仅凭 total variation 也不能自动得到物理事件数。

## 4. 同一 JJ 的相位—面积双证据

Josephson 关系为：

\[
V_J=\frac{\Phi_0}{2\pi}\frac{d\phi}{dt}
\]

因此：

\[
\frac{1}{\Phi_0}\int_{t_a}^{t_b}V_J(t)\,dt
=\frac{\phi(t_b)-\phi(t_a)}{2\pi}
\]

只在下列条件全部相同时使用该等式交叉校验：

- 同一个 JJ；
- 同一对正负端点；
- 相同符号方向；
- 相同积分时间窗；
- 同一次运行。

使用 CSV 的实际 `time` 列进行梯形积分，不假定固定采样间隔。优先输出 JoSIM 对该支路的直接 `V(B...)`；若只能使用节点电压差，必须登记端点和方向。节点对地电压只有在另一端确实接地时才等于结电压。

相位—面积差异超过冻结容差时，先检查方向、端点、窗口、采样和列映射，不挑选更有利的一个指标。

## 5. 下游与系统证据

本地 JJ 净转一圈只说明该 JJ 的局部响应。下游接收至少需要：

- 输出确实连接声明的负载/标准 JTL；
- JTL 各级在对应因果窗中出现离散稳定平台；
- 一个输入对应一个下游增量，零输入/read0 无增量；
- 事件后无持续运行态；
- 更细时间步下分类不变。

没有 JTL 的网表不得判“JTL 成功”或“JTL 失败”。周期平台可以作为回归证据，但不能替代单次输入的因果验证。

系统层还要求重复读、状态保持、时序和真实负载按冻结规范通过。仿真系统 PASS 不推出硬件必然成功。

## 6. 数据有效性和三态判定

先检查：原始文件、网表、版本、列、时间轴、NaN/Inf、求解器日志、控制、方向、稳定窗、负载、规格和步长。

- 必要条件全部满足：可按规范判 `PASS`。
- 数据有效且必要条件明确不满足：判 `FAIL`。
- 缺少关键证据、容差未冻结或步长改变分类：判 `INCONCLUSIVE`。
- 数据损坏、求解失败或截断：标记 artifact `INVALID`，不评价电路功能。

## 7. 校准样例与禁止用法

校准/回归优先使用当前仓库中的：

- `test/standard/test_jtl.cir`：已知输入数量的标准 JTL；
- `test/final/interface/data/test_dcsfq_behavior_bump_0.csv` 与 `..._300u.csv`：零输入背景相减样例；
- `test/final/qb/data/bq_v4_sweep*.csv`：周期下游平台样例；
- 合成的 0→\(2\pi\) 台阶和不规则时间采样数据。

每次使用前读取当前 `docs/HANDOVER.md`，因为历史 JSON 和结论文档可能已被 supersede。

禁止：

- 使用 `scripts/sfq_metrics.py` 的 v1 字段作为当前物理 Gate；
- 把 `fast_events` 或过阈值样本数称为脉冲数；
- 把 `-j 2pi` 图的纵轴直接称为 SFQ count；
- 用一个 JJ 的相位绕转证明闭环 fluxoid 数；
- 用内部结活动证明下游接收；
- 在缺 JTL、缺 read0 或缺步长收敛时宣布系统成功；
- 将机制推断写成已证实原因而没有单变量对照。
