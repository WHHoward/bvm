# BVM QB threshold-ordering boundary search

This experiment contains exactly two registered midpoint parameter points,
each with masks 0011 and 0111: four new full physical closed-loop solves at
fixed L3=1.6 pH. Endpoint files are immutable context only and are not counted
as new solves.

CONTROL/history is evaluated only in the registered 70–110 ps windows using
complete QBOUT-to-JTL6 propagation. Final-read and tail phase rollback is a
separate diagnostic and never a CONTROL criterion. P(...) remains raw radians;
rad/(2*pi) is navigation/display only, never an SFQ count. N1/N4 validation,
additional midpoints and timestep refinement require later authorization.
