# Full closed-loop QB screening — evidence brief

Scientific interpretation is bounded to the declared current BVM/JSL source,
QB/JTL receiver, stimulus, numerical grid and executed prefix.

The screening table records each parameter point's one-factor change, control
status, N2/N3 raw-supported response candidates, fourth-response diagnostics and
candidate class. Existing baseline/reuse cases remain immutable and are never
counted as fresh solves. A direct S candidate stops broad screening; no
combination or later positional/timestep study starts automatically.

No phase landmark, voltage area, terminal area, threshold activity or current
peak is treated as an SFQ count. The final candidate status is recorded only
after raw, independent and package QA.
