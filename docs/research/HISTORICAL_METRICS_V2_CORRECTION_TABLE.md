## The correction

Legacy metric scripts read JoSIM phase-mode `P(...)` columns as raw radians but
reported them as if they were already in turns (or counted over-threshold
samples as "events"). The V2 correction is:

```
endpoint_delta_turns = (P_last - P_first) / (2*pi)   # sign preserved, raw rad retained
```

No absolute value, rounding, or modulo is applied. The full-record interval
`[0, run_end + dt)` is a provenance interval, not a pre/post stability window,
and the result is never labelled a platform result, activity, event, SFQ,
fluxoid, voltage-area, convergence verdict, or physical Gate.

## Gate boundary

Each family remains below any physical Gate claim. The outputs report
**historical endpoint arithmetic and artifact provenance only**; they do not
establish an SFQ, fluxoid, downstream reception, candidate, route, interface,
or system verdict, and no global tolerance is frozen by this table
(METRIC_SPEC_V2 §8: tolerances remain `UNFROZEN`/`UNKNOWN`).
