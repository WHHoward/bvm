> **状态**: 设计已获用户批准 (2026-08-06) | **修订 (2026-08-06)**: 缩放起点改为以 BVM 实测输出行为为准，新增 P0.0 输出表征 | 下一步: writing-plans 实施计划

## 1. 背景与问题定义

BVM 读"1"在 SL 端给出 ~68.4µA、30-40ps 的慢衰减电流；读"0"给出 ~1.4µA。
**目标**（GPT §十.5 冻结口径）: 读"1" → 恰好 1 个被下游 JTL 接收的 SFQ；读"0" → 0 个且无误触发。

现有 BQ 经 8 轮实验系统性排除（证据链 §4），冻结根因：

1. **BJs 裸结无外部阻尼**（βc≈5.4 欠阻尼）→ 任何过驱动 ≥1.4×IC 即电压态滑移
2. **电流源注入 = 通量泵** → 滑移量窗口依赖（602-829 SFQ/300ps），无离散性
3. **输出级驱动不足** → ~100µA < ColdFlux JTL 阈值 250µA，下游 JTL 收到 0
4. **v4 IC 顺序修正副作用** → 输出传递路径死亡（输出比 v2 差 5.5×）

### 接口规格输入：BVM 输出行为（缩放起点的依据）

> 缩放起点**必须以 BVM 实测输出为规格**，而非仅按 IC 比例推算（2026-08-06 修正）。

| 量 | 已知值 | 来源 |
|---|---|---|
| R1 读出峰值电流 | 68.4µA（带 8-JJ 负载链，30-40ps 慢衰减） | BASELINE.md §3 |
| R0 读出峰值电流 | ~1.4µA | BASELINE.md §3 |
| BVM 独立测试 I_SL 峰值 | 75.74µA @39.1ps（无级联负载） | BASELINE.md §3 |
| SL 源阻抗 | ~15Ω（**读出量随负载改变**） | bq_cell.cir 注释 + GPT §九.2 |
| 写入态 | 多涡旋（JM1 settle +5.93 SFQ），读1/0 电流对比强 | BASELINE.md §4.2 |

**推论**: 负载会改变实际到达接口的电流（68.4 vs 75.7µA），因此 P0.0 必须先完成负载扫描，产出接口规格（I_peak、有效宽度、源阻抗、读1/0 差分裕度），再定缩放起点。目标工作点：触发阈值位于读0 与读1 之间，两侧各留 ≥2× 裕度。

## 3. 元件拓扑与参数

### 拓扑

```
a ─ L1(1.67p) ─ node1 ─ L3(0.6p) ─ B1(80µA) ─ L4(1.1p) ─ B2(80µA) ─ L5(4.5p) ─ B3(250µA) ─ L6 ─ q
                  │                                            │
                  L2(3.9p) 到地                                IB2=175µA (70%×B3, 不变)
IB1≈100µA ─ LB1 ─ node3 ─(B1/B2 支路间分流)
```

### 参数表

| 参数 | 原 DCSFQ | DCSFQ_BVM | 依据 |
|---|---|---|---|
| B1/B2 area | 2.25 (225µA) | **0.8 (80µA)（起点）** | 以 P0.0 BVM 实测规格定稿；当前按 68.4µA 推算：触发阈值 ≈25µA，读1 → 2.8× 裕度，读0 → 远离阈值（2026-08-06 起改为实测驱动） |
| IB1 | 275µA | **≈100µA** | 按 80/225 比例缩放，保持 ~60-70% 工作点（P0.2 后微调） |
| RB1/RB2 | 3.05Ω | **≈8.6Ω** | RB = 6.86/area 公式（6.8599/0.8 = 8.57Ω） |
| LRB1 | 1.72pH | **≈4.85pH** | (RB/Rsheet)·Lsheet 公式 |
| LRB2 | 2.22pH | **≈5.35pH** | (RB/Rsheet)·Lsheet + LP 公式 |
| B3 / IB2 / L1-L6 / LB1 / LB2 | — | **全部不变** | 输出级与输入网络保持标准 ColdFlux 配方 |

参数在 Phase 0（P0.2 电流分流标定）后按实测微调；**B3、L6、IB2 冻结不动**。

## 4. Phase 0 诊断实验（先测行为，再定稿参数）

| # | 内容 | 判定 → 下一步 |
|---|---|---|
| P0.0 | **BVM 输出行为表征（负载扫描）**: 短接/小电阻/12Ω/几十Ω/8-JJ 链/直接接 DCSFQ_BVM（GPT §九.2） | 产出接口规格：I_peak、有效宽度、源阻抗、读1/0 差分裕度 → **该规格决定缩放起点** |
| P0.1 | 现有 `circuits/standard/DCSFQ.cir` 跑输入形态：单次 pwl 68µA/30-40ps 凸包 + 阈值扫描 0-150µA | 边沿触发 → 方案一继续；电平触发滑移 → 升格方案二 |
| P0.2 | DCSFQ_BVM 电流分流标定：I(B1 支路) vs I(端口 a)（以 P0.0 实测输入电流为准） | 定"端口输入 ↔ B1 实际电流"换算系数，冻结最终参数 |
| P0.3 | 确定性：每次运行 ≥2 次，md5 一致 | 全流程标准动作 |

**执行顺序: P0.0 → P0.1 → P0.2 → P0.3**（P0.0 与 P0.1 可并行——前者测 BVM、后者测 DCSFQ，互不依赖）。P0.1 直接使用现有标准件——零设计成本回答"思路是否成立"。
