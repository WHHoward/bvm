## 1. 背景与问题定义

BVM 读"1"在 SL 端给出 ~68.4µA、30-40ps 的慢衰减电流；读"0"给出 ~1.4µA。
**目标**（GPT §十.5 冻结口径）: 读"1" → 恰好 1 个被下游 JTL 接收的 SFQ；读"0" → 0 个且无误触发。

现有 BQ 经 8 轮实验系统性排除（证据链 §4），冻结根因：

1. **BJs 裸结无外部阻尼**（βc≈5.4 欠阻尼）→ 任何过驱动 ≥1.4×IC 即电压态滑移
2. **电流源注入 = 通量泵** → 滑移量窗口依赖（602-829 SFQ/300ps），无离散性
3. **输出级驱动不足** → ~100µA < ColdFlux JTL 阈值 250µA，下游 JTL 收到 0
4. **v4 IC 顺序修正副作用** → 输出传递路径死亡（输出比 v2 差 5.5×）

### 接口规格输入：BVM 输出行为（缩放起点的依据）

> 缩放起点**必须以 BVM 实测输出为规格**，而非仅按 IC 比例推算（2026-08-06 修正）。

| 量 | 已知值 | 来源 |
|---|---|---|
| R1 读出峰值电流 | 68.4µA（**8-JJ 链 + BQ 输入分流**的加载值；纯链 79.55µA） | BASELINE.md + P0.0 异常定位 |
| R1 峰值范围（负载相关） | **43.9-97.8µA**（50Ω→短接） | P0.0 实测 |
| R1 脉冲 FWHM | **6.8-11.2ps**（30-40ps 是 SE 驱动窗口，非脉冲宽） | Task 6 补测 |
| R0 读出（窗口内稳态） | ~1.4µA；但 SE 边沿振铃 **±40µA**（低负载） | P0.0 实测 |
| SL 源阻抗 | **Zth ≈ 39.6-41.2Ω**（实测，原 ~15Ω 假设废止） | P0.0 实测 + Task 6 复核 |
| 读1/0 差分裕度 | ≥31µA（窗口定义，12/50Ω 最差） | P0.0 |
| 写入态 | 多涡旋（JM1 settle +5.93 SFQ），读不破坏存储（JM1 负载不变） | BASELINE.md + P0.0 |

**推论（2026-08-06 Phase 0 更新）**: 接口规格已实测（P0_LOG.md §2）。**触发阈值必须同时满足**: ① 高于 R0 窗口 SE 边沿振铃（~40µA 量级）；② 读1 过驱动 ≤1.5×（P0.1: 过驱动 ~1.4× 即多滑移爆发）→ **阈值目标 45-55µA**（原 25µA/2.8× 裕度废止）。

### 参数表

| 参数 | 原 DCSFQ | DCSFQ_BVM | 依据 |
|---|---|---|---|
| B1/B2 area | 2.25 (225µA) | **0.8 (80µA)（起点）** | Phase 0 实测修订: 阈值目标 45-55µA（读1 过驱动 ≤1.5×，高于 R0 振铃）；80µA 起点在 68.4µA 下不触发（增量耦合 0.285），V2 扫描最终裁决（可能下调至 ~0.6 或调输入网络） |
| IB1 | 275µA | **≈100µA** | 按 80/225 比例缩放，保持 ~60-70% 工作点（P0.2 后微调） |
| RB1/RB2 | 3.05Ω | **≈8.6Ω** | RB = 6.86/area 公式（6.8599/0.8 = 8.57Ω） |
| LRB1 | 1.72pH | **≈4.85pH** | (RB/Rsheet)·Lsheet 公式 |
| LRB2 | 2.22pH | **≈5.35pH** | (RB/Rsheet)·Lsheet + LP 公式 |
| B3 / IB2 / L1-L6 / LB1 / LB2 | — | **全部不变** | 输出级与输入网络保持标准 ColdFlux 配方 |

参数在 Phase 0（P0.2 电流分流标定）后按实测微调；**B3、L6、IB2 冻结不动**。
