# R2-A K matrix plot

This standalone matrix compares all registered mutual-coupling points K=0.60, 0.70, 0.80, 0.90 and 0.95. It is descriptive only; the formal R2-A report remains the authority for phase/area and discrimination conclusions.

Panels use the exact raw CSV headers `P(B_OUT|XTRIG)`, `P(B_TRIG|XTRIG)`, and `V(N_SEC|XTRIG)`. Phase is displayed as raw phase divided by 2π (turns); voltage is displayed in microvolts. The plot does not count events.
