**一、T1 单元 总览（网表式文档）**

> 最后更新：2026-05-30

1. 目的与适用场景
-	用途：`T1` 为多结耦合的相位累积／量化单元，接收来自阵列或前级的微小/缓变电流，借助局部约瑟夫森结将其量化为 SFQ 脉冲并输出到后级。常用于阵列读写接口、整形与短期相位存储。

2. 拓扑概览（文本网表）
```
.subckt T1 I C IB1 IB2 IB3
* 主链与偏置（示意）
L1 I N1 0.213p
J1 N1 0 T1_J1
L2 N1 N2 1.6p
J2 N2 0 T1_J2
L3 N2 N3 2.028p
RB1 N2 IB1 6.8
* 中心耦合环路
L7 N3 N4 1.219p
J4 N4 0 T1_J4
J5 N4 0 T1_J5
L8 N4 N5 1.383p
L9 N5 N6 5.366p
* 输出整形
RB2 N6 IB2 6.8
J10 N6 N7 T1_J10
L14 N7 C 4.6p
RB3 N7 IB3 16
.ends T1
```

（注：上为示意网表片段，结名 `T1_Jx` 作为模型占位，具体连线/节点视图可按下文节点命名映射。）

3. 端口说明
-	`I`：主输入（来自上级 BVM/BQ 等），低幅度或脉冲序列。
-	`C`：主输出（驱动下级或输出总线）。
-	`IB1/IB2/IB3`：偏置/抽流端口，用于注入静态偏流或吸收能量以调整复位/阻尼行为。

4. 参数清单（推荐以 `.param` 管理）

- 电感（pH）
    - `L1`=0.213, `L2`=1.6, `L3`=2.028, `L4`=0.153, `L5`=0.6,
        `L6`=2.337, `L7`=1.219, `L8`=1.383, `L9`=5.366, `L10`=0.905,
        `L11`=0.957, `L12`=1.219, `L13`=1.009, `L14`=4.6, `L15`=1.297,
        `L16`=4.644, `L17`=2.0

- 电阻（Ω）
    - `RB1`=6.8, `RB2`=6.8, `RB3`=16

- 结电流示例（µA，建议作为参考并以模型为准）
    - `T1_J1`/`T1_J2` = 350
    - `T1_J3` = 180
    - `T1_J4` = 80.3, `T1_J5` = 77.9, `T1_J6` = 105.1
    - `T1_J7`/`T1_J8`/`T1_J9` = 100
    - `T1_J10` = 86.9, `T1_J11` = 150

5. 节点命名约定（建议）
-	`N_I`：输入直连节点
-	`N_PRE`：输入前置处理节点
-	`N_LOOPx`：中心耦合环路节点（用于描述相位累积）
-	`N_OUT`：输出前端节点

6. 工作原理要点（对比 BVM 风格说明）
-	事件化量化：T1 通过局部约瑟夫森结对持续或缓变电流进行“离散化”——当环路相位累积超过阈值时，结翻转并释放 SFQ 脉冲，输出响应以脉冲序列为准（逐事件响应），而非对输入电流做一次线性求和后统一响应。
-	相位累积与阈值：中心闭合环路（`N_LOOPx`）允许在短时间内存储相位；阈值由环路电感、结 Ic 与偏置决定，偏置端口（`IBx`）可调整灵敏度与复位时间。
-	阻尼与复位：`RBx` 提供阻尼与能量耗散，防止自激振荡并影响复位速度；在高 RN（高 Q）模型下建议增加并联阻尼或局部 R_shunt。

7. 推荐模型映射（与仓库现有模型对齐）
-	若使用仓库中的模型集合（见 [description.md](description.md) 中的 `mitll_models`、`coldflux` 等）：
    - 将 `T1_J1/J2` 映射到高 Ic 模型（如 `jj320` 或自定义 area×基础模型）用于承担输入开关。
    - 中环检测结（`T1_J4..J6`）可映射到 `qb_js` 类低 Ic 模型以获得易开关特性。
    - 若发现欠阻尼或振荡，给关键结加 `R_shunt=10..30Ω`（类似 `BQ_RS` 变体）。

8. 已知问题与调优建议
-	结 Ic 选择敏感：若旁路结 Ic 过低，会将输入分流，降低主通路灵敏度；若 Ic 过高，则可能永不触发（类似 description.md 中的 JL2 问题）。
-	阻尼要求：裸结在不同模型库下表现差异大，建议在早期仿真中尝试 `mitll_models_mixed.cir` 或 `coldflux`，并根据需要添加 R_shunt。
-	半选/误触发：像 BVM 一样，单一路 WL/BL 弱注入可能引起半选误写；在阵列环境中需评估并行偏置条件。

9. 验证/测试建议
-	基本单元测试：建立最小 `.cir` 调度，注入阶跃或脉冲到 `I`，测量 `C` 的 SFQ 输出计数与时间序列（使用 `josim-cli` 产生 CSV 比对）。
-	灵敏度扫描：以 `IB1/IB2/IB3`、`RBx`、以及关键结的 `area` 为参数做扫描，绘制触发阈值与复位时间的曲线。
