# JoSIM BVM + QB 项目最终总结

> **日期**: 2026-05-17 | **仿真器**: JoSIM v2.7 | **工艺**: MITLL SFQ5ee

---

## 一、项目目标

复现论文中的 BVM（双稳态涡旋存储器）+ QB（量化缓冲器）电路，实现：
- BVM 存储/读出功能
- QB 将 BVM 输出电流转换为 SFQ 脉冲
- 多 BVM 阵列共享 SL → QB → 输出完整链路

**参考论文**:
- BVM: Karamuftuoglu et al., *Supercond. Sci. Technol.* 38 015020 (2025)
- BQ: Razmkhah et al., *Supercond. Sci. Technol.* 37 065011 (2024)
- MVM: Karamuftuoglu et al., arXiv:2507.04648 (2025)

## 二、已完成的工作

### 2.1 BVM 单元（独立验证）

| 步骤 | 内容 | 结果 |
|------|------|------|
| 建模 | 按论文 Fig.2(b) 所有参数建立 subcircuit | 电路: `circuits/bvm/bvm_cell.cir` |
| 写入 W1 | WL+BL=100μA, 10ps | P_JM1 = +13.4 rad (2.1Φ₀) ✓ |
| 写入 W0 | WL+BL 反向 | P_JM1 翻转至负值 ✓ |
| 读出 R1 | SE=100μA, 10ps | I_SL = 32.3 μA ✓ |
| 读出 R0 | SE=100μA, 10ps | I_SL ≈ 12.6 μA ✓ |
| R1/R0 区分 | — | 2.5-2.6× ✓ |
| 半选保护 | WL-only / BL-only | ΔP_JM1 < 1 rad ✓ |
| NDRO | 读后检查相位 | P_JM1 不变 ✓ |

**BVM 验证结论**: 单元功能完全正确，论文参数可复现。

### 2.2 QB 单元（独立优化）

| 步骤 | 内容 | 结果 |
|------|------|------|
| 原始 QB | JS=133μA, 无 shunt | BVM 电流 (32μA) 无法触发，IC 太高 |
| Q1: JS IC 扫描 | 20/25/28/30/35μA | JS=25μA 最优 — 32μA→1.2Φ₀ |
| Q1b: IBias 扫描 | 20-100μA | 无影响（IBias 走并联支路） |
| **C1: 并联分流电阻** | JS 两端并联 10Ω | **关键突破** — βc 从 1.14→0.28, 抑制 LC 振荡, 准离散台阶 |
| C1 验证 | 0/32/64/96/128μA 理想电流源 | 32μA→1.0Φ₀, 64μA→2.4Φ₀, 96μA→3.6Φ₀, 128μA→5.3Φ₀ |

**QB 独立验证结论**: 用理想电流源（10ps脉宽）时，QB 能按电流幅值产生准离散相位累积。但**不是真正的离散 2π SFQ 脉冲**。

### 2.3 BVM 输出优化尝试（未采用）

| 方案 | 改动 | 最佳 I_SL | 结论 |
|------|------|----------|------|
| P1: JS IC↑ | JS 74→90μA | 16μA (R1/R0=1.0×) | ✗ 存储磁通不足 |
| P2A: JSL | LSL→4×jj320 | 31.6μA (R1/R0=2.6×) | △ 不提升 I_SL |
| A1: ISE 扫描 | ISE 100→180μA | 35.4μA | △ +10% |
| A2: IWL 扫描 | IWL 80→150μA | 37.2μA | △ 边际 |
| A3: 联合网格 | ISE×IWL 12 点 | 37.7μA | △ +17% |
| B1-B3: JM1+JS | 多种组合 | 13-27μA | ✗ 全部失败 |

**结论**: BVM 输出 32μA 是论文参数下的物理极限。正确方向是调整 QB 匹配 BVM，而非反之。

### 2.4 BVM + QB 集成

| 步骤 | 内容 | 关键发现 |
|------|------|---------|
| D1/D3 | BVM→QB (无 jj320) + 多 BVM 尝试 | 2+ BVM 矩阵奇异 |
| D2 | 单 BVM→QB 直连 (无 jj320) | 电流确实流入 QB，但响应弱 (0.2Φ₀) |
| **串联拓扑** | 用户纠错: jj320 必须与 QB **串联** (SL→jj320→QB→GND) | **19× 增强** QB 响应 |
| 4BVM 串联 | 4 BVM + 1×jj320 + QB 串联 | **成功运行**, 4 cell→1.55Φ₀ |

## 四、遇到的问题与状态

### 4.1 已解决 ✓

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| BVM 功能验证 | — | 按论文参数直接复现 |
| QB 无法触发 (IC 太高) | JS=133μA >> BVM 输出 32μA | JS IC 降至 25μA |
| QB 相位连续振荡 | 欠阻尼 (βc≈1.1), LC 振荡 | C1: 并联 R_shunt=10Ω, βc→0.28 |
| **jj320 并联分走电流** | 用户指正: jj320 应串联而非并联 | 改为 SL→jj320→QB→GND |
| 2+ BVM 矩阵奇异 | 共享 SL 节点缺少相位参考 | 保留至少 1 个 jj320 串联 |

### 4.2 部分解决 △

| 问题 | 状态 |
|------|------|
| JS=25μA+R_shunt 改善相位离散性 | 准离散，但不产生真正的 2π 整数跳变 |
| 4BVM I_SL 线性度 | 基本线性 (1×:2.0×:2.9×:3.8×)，但非完美 1:2:3:4 |

### 4.3 未解决 ✗

| 问题 | 原因分析 |
|------|---------|
| **QB 不产生离散 SFQ 脉冲** | 10ps 脉宽太短，JS 结来不及完成完整 2π 转换。SFQ = ∫V·dt = 2.07mV·ps，当前 V_JS<0.3mV 且脉宽<10ps |
| **V_OUT 始终为零** | JL2 结从未触发。QB 输出级完全无响应 |
| **4BVM 单读时漏电** | 非读取 BVM 的 R-loop 提供超导旁路到地（~12Ω/条）。整列同时读时无此问题 |

## 五、与论文预期的对比

| 论文声称 | 我们的结果 | 差距 |
|---------|-----------|------|
| BVM 读写功能 | ✓ 完全复现，I_SL=32μA, R1/R0=2.5× | 无差距 |
| BVM→jj320→QB 串联 | ✓ 串联拓扑验证成功 | 无差距 |
| 多 BVM 电流在 SL 累加 | △ I_SL 累加基本线性 | 线性度不完美 (3.8× vs 4×) |
| QB 按电流幅度输出对应脉冲数 | ✗ 不产生离散脉冲，仅连续相位 | **根本性差距** |
| MVM 用 JoSIM 得到 0-4 脉冲 (Fig.2b) | ✗ 我们无法复现 | 论文似乎用了不同的 QB 设计 |

### 论文"修改"的关键

MVM 论文 §2.2 说 BQ 需要 "modification" 来检测单个 BVM 输出，但**不提供具体方案**。我们的全套实验表明：
- JS IC 调整 + R_shunt 优化只能得到连续相位累积
- 要在 10ps 脉宽下产生离散 SFQ，可能需要**完全不同的 QB 前端设计**（如脉冲展宽电路、锁存机制、或 DC/SFQ 转换器）

## 七、如果继续，可以尝试的方向

1. **脉冲展宽**: 在 jj320 和 QB 之间插入 pulse-stretching 电路
2. **DC/SFQ 转换器**: 将 BVM 模拟电流先转 SFQ 脉冲列再送入 QB
3. **JS 进一步优化**: 调整 JS 的 RN/CAP（直接修改 JJ 模型参数而非外并电阻）
4. **T1 加法器**: 跳过 QB，直接测试 T1 能否检测 BVM 输出
5. **联系论文作者**: 询问 MVM 论文中 BQ "modification" 的具体方案
