# 第 1 章 物理原理深讲

## 1.1 超导为什么会电阻为零（够用的深度）

【定律】1911 年昂内斯发现汞在 4.2K 以下电阻突然变为零。1957 年 BCS 理论解释：低温下电子两两配对（库珀对），所有库珀对进入**同一个量子态**，整个超导体就像一个巨大的"量子波"。普通金属里电子被杂质散射产生电阻；超导体的"集体波"不会被散射——就像一列整齐行进的队伍不会被单个障碍绊倒。

**对本文档有用的两个推论**：
1. 超导电流一旦建立就**无损耗持续**（存储器的基础）
2. 描述超导体需要"波"的语言——**相位**（波的相位）成为电路变量（约瑟夫森结的基础）

## 1.2 约瑟夫森结：两条方程从哪来

【定律】1962 年约瑟夫森预言：两个超导体中间夹薄绝缘层（S-I-S 三明治），两侧的"量子波"会穿过绝缘层微弱重叠，产生电流。两个"波"重叠时，电流取决于它们的**相位差** φ：

```
第一方程：I = IC · sin(φ)          （电流由相位差的正弦决定）
第二方程：V = (Φ₀/2π) · dφ/dt      （电压 = 相位变化速度）
```

第二方程的物理来源【定律】：量子波随时间演化，相位变化率正比于能量差（电压 × 电子电荷）。量纲直觉：**"1 mV 电压 = 相位每皮秒前进约 0.48 圈"**（精确值 483.6 GHz/mV，交流约瑟夫森效应）。

**这两个方程就是结的"行为说明书"**——后面所有现象（滑移、振铃、多脉冲）都能从它们推出来。

## 1.3 从方程推出关键行为（只需要代数）

**情形 A：结两端加恒定电压 V**
→ dφ/dt = 常数 → 相位匀速前进 → I = IC·sin(ωt)，电流正弦振荡（交流约瑟夫森效应）。**结在电压态下相位一直转，每转一圈（2π）释放一个磁通量子。**

**情形 B：往结里灌恒定电流 I > IC**
→ sin(φ) 最大只能是 1，所以 I > IC 时结必须"跳"到电压态（情形 A）——然后相位持续前进，持续释放磁通量子。

> **这就是"滑移"的机制**【定律】：结一旦进入电压态，只要电压不归零，相位就一直转，每 2π 就是一个磁通量子。滑移"多少"取决于**持续了多久**——这解释了为什么滑移量依赖窗口（见 4.1 节）。

## 1.4 RCSJ 模型——我们实际仿真的东西

真实的结不是理想的"sin 函数电流源"，它等效为【定律，McCumber/Stewart 1968】：

```
真实结 = 理想结 ∥ 电阻 RN ∥ 电容 C
（理想结 ∥ 表示三个元件并联，各自分走一部分电流）
```

并联电路要用**基尔霍夫电流定律（KCL）**（见 2.1 节）：节点流入总电流 = 三路之和：

```
I = IC·sin(φ) + (Φ₀/2πRN)·dφ/dt + (Φ₀C/2π)·d²φ/dt²
    ↑ 理想结项    ↑ 电阻项（阻尼）     ↑ 电容项（惯性）
```

- **电阻项**：像摩擦，把振荡能量耗散掉（阻尼）
- **电容项**：像质量，给系统惯性——相位变化"刹不住车"

**阻尼参数 βc**【定律】：`βc = 2π·IC·RN²·C / Φ₀`。
- βc ≫ 1：惯性主导 → 翻转后**振铃**
- βc ≪ 1：摩擦主导 → 翻转后**干净停住**
- **为什么 jjmit 所有结 βc ≈ 5.4 与面积无关**【定律】: 结面积 A 增大时 IC∝A、RN∝1/A、C∝A，三者代入 βc 公式：A·(1/A)²·A = 常数。所以**缩小结不会让它更听话**——这是"缩放 IC 救不了欠阻尼"的定量原因之一。

## 1.5 磁通量子化的"为什么"

【定律】超导环里的"量子波"绕环一周必须**回到自身**（相位绕一圈变化必须是 2π 的整数倍）。而相位绕环的变化又正比于环内的磁通（相位-磁通关联）。两者结合推出：

**环内磁通 = n·Φ₀（n 是整数），Φ₀ = 2.07×10⁻¹⁵ Wb**

- 这是 BVM 存储（涡旋 = n 个 Φ₀）和 SFQ 数字性（每个脉冲恰好 1 个 Φ₀）的共同根源【定律】
- 推论：结翻转一次释放的能量是**量子化的**——数字逻辑需要的"每个 1 都一样大"在物理上被保证【定律】

## 1.6 时间尺度直觉（用到的所有数字）

| 量 | 值 | 直觉 |
|---|---|---|
| 1 SFQ 的面积 | Φ₀ = 2.07 mV·ps | 电压脉冲的时间积分必须等于它 |
| SFQ 脉冲宽 | ~2ps【实测，项目仿真约定】 | 平均电压 ~1mV |
| BVM 读出电流脉冲 | FWHM 7-11ps【实测 P0.0】 | 比 SFQ 宽 3-5 倍，且振荡 |
| BQ 输出峰值 | 157µV【实测 BASELINE】 | 面积 ≪ Φ₀ → 不是 SFQ 事件 |
| 结的小信号电感 | L_J = Φ₀/(2π·IC)【定律】 | 50µA 结 → 6.6pH；20µA 结 → 16.5pH |

**L_J 公式的用处**：结在小信号下像一个电感。IC 越低 L_J 越大——这就是"L_J 矛盾"（降低阈值 → 输入电感增大 → 电流被电感吃掉）的定量基础【定律 + 项目推导】。

# 第 2 章 电路设计工具箱（你需要补的电路知识）

> 高中电路讲的是"稳态电阻电路"。超导电路设计需要四件新工具：**基尔霍夫定律、并联分流、时间常数、阻抗直觉**。全部用直觉讲，不用解方程。

## 2.1 基尔霍夫定律

- **KCL（电流守恒）**：任何一个节点，流入的电流 = 流出的电流。类比：水管汇合处，流入的总水量 = 流出的总水量。【定律】
- **KVL（电压守恒）**：沿任意闭合回路走一圈，电压升的总和 = 电压降的总和。类比：爬山回到原点，总升高 = 总降低。【定律】

**它们在本文档里被用在哪**：分析"输入电流被 L2 分流"（KCL 在 node1）、"偏置电流怎么分给 B1/B2 支路"（KCL 在 node3）。

## 2.2 并联分流——理解"电流被谁抢走"

两条并联路径，电流按**阻抗反比**分配【定律】：

```
I₁/I₂ = Z₂/Z₁
```

超导电路里路径主要是电感，而**电感的阻抗（感抗）与频率成正比**【定律】：

```
Z_L = 2πfL    （f 是信号频率，L 是电感值）
```

**关键推论**：
- **直流（f→0）**：电感阻抗 → 0，直流**全走电感**（短路）
- **高频（f 大）**：电感阻抗大，高频**讨厌走大电感**

数值例子（DCSFQ 输入网络）：L2 = 3.9p 到地，L3 = 0.6p 到结。在 ~30GHz 下：Z(L2) ≈ 0.74Ω，Z(L3) ≈ 0.11Ω → 理想分流比约 6.5:1 偏向 L3。**但实测只有 0.285 的电流到了结支路**——为什么差这么多？答案在第 4.5 节（偏置环流的方向抵消 + 结的非线性）。这个"理论分流 vs 实测"的差异是 Phase 0 最重要的发现之一。

## 2.3 时间常数——"快"和"慢"的标尺

电感电路的特征时间【定律】：`τ = L/R`（电流建立或衰减到 63% 需要的时间）。**电流在电感里不能突变**（2.3 节直觉：电感像水流里的涡轮，突然改变水压，涡轮要转一会儿才跟上）。

用在哪：
- 为什么 BVM 读出"慢"：电流经过输出链的 L(0.5p) 和 R(12Ω)，τ ≈ 0.04ps 量级——其实单看很快；真正的"慢"是读环的响应（S-loop 电感 12-25p，τ 更大）
- 为什么 SFQ 脉冲要"快"：结翻转产生相位突变，电感网络把它变成 ~2ps 的电流脉冲【实测】

## 2.4 阻抗直觉——源阻抗为什么重要

一个信号源（我们测出 Zth ≈ 40Ω、Vth ≈ 3.9mV【实测 P0.0】）接负载 R_L 时：

```
I_load = Vth / (Zth + R_L)
```

- R_L 越小，电流越大（短接 97.8µA）；R_L 越大，电流越小（50Ω 只有 43.9µA）【实测 P0.0】
- 这就是为什么"负载是设计变量"——**接口设计本质上是在选负载阻抗**

## 2.5 偏置（Bias）——给元件设工作点

**偏置 = 预先往结里灌一个电流，让它"半只脚踩在阈值上"**。

为什么偏置到 ~70% IC：
1. 输入只需要再补 ~30% 就触发 → 灵敏度高
2. 触发后结电流回到 70% < IC → **自动复位**（这是"干净翻转"的机制）【推断，与标准 RSFQ 设计方法一致】

对比：BQ 的 BJs **没有明确偏置**（标称 IBias 走的是别的节点，不直接落在 BJs 上【实测 + 拓扑分析】）→ 它"踩空"了，输入一超 IC 就彻底失控（无复位机制）。

## 2.6 "阈值判别器"的设计逻辑

一个判别器要满足三个条件（我们 DCSFQ_BVM 的设计目标）：
1. **偏置近阈值**：静态时电流 < IC，差一点点
2. **输入补一刀**：读"1"的电流把它推过 IC；读"0"推不过
3. **事件后复位**：翻转后电流回落到 < IC

**为什么阈值窗口上下有界**（这是 Phase 0 定出的 45-55µA 的由来）：
- **下界**：高于读"0"时的干扰（R0 窗口 SE 边沿振铃 ±40µA【实测 P0.0】）——否则读"0"误触发
- **上界**：读"1"的过驱动 ≤1.5×IC（300µA 时 ~1.4× 就多脉冲【实测 P0.1】）——否则读"1"触发一串

# 第 3 章 元件设计深讲（为什么长这样）

## 3.1 JTL 的阻尼网络（RB + LRB）——每个元件干什么

标准 JTL 每个结配一个网络：**RB（电阻）串联 LRB（电感），接到地**。

- **RB 干什么**：翻转后给结电流一个泄放路径，让结电流尽快降到 IC 以下（刹车）【推断，机制一致】
- **LRB 干什么**：让刹车"挑信号"。高频时 LRB 感抗大 → 刹车对快信号（SFQ 脉冲）透明，不干扰传递；低频/直流时 LRB 是短路 → 刹车对慢分量有效【推断，机制一致】
- **RB 的值怎么定**：ColdFlux 方法论 `RB = 6.86/area`——数值上它**恰好等于**该结的临界阻尼电阻 √(L_J/C)。证明【定律 + 代数】：L_J = Φ₀/(2π·IC) = 3.29pH/area（IC = area×100µA），C = area×0.07pF，所以 √(L_J/C) = √(47)/area ≈ 6.86/area = RB。即"正好让秋千荡两下就停"的刹车力度——而标准件的参数恰好就是按这个设计的

**为什么这个网络是 BQ 失败的核心对照**：JTL 有刹车 → 干净翻转【实测：标准元件全部验证通过】；BQ 的 BJs 没刹车 → 滑移【实测】。同一模型（βc≈5.4 一样），差别全在外部网络。

## 3.2 BVM 的结构——两个环各干什么

```
S-loop（存储环）:  N1→JM1→LM1→地，N1→LM2→JM2→N2→LM3→N5→LPM→地
R-loop（读环）:    N2→LS1→JS1→N3，N5→LS2→JS2→N6，N3→RS(3Ω)→N6
输出链:           N6→LPSL(0.5p)→RSL(12Ω)→N8→LSL(0.4p)→SL
```

- **为什么两个环**【推断，按设计意图解释】：存储环（大电感 12-25p）负责"扣住"涡旋；读环（小电感 0.5p）负责"探测"——探测时大电感环不动（涡旋保住），小电感环响应快。**读不破坏存储【实测 P2：100µA 读漂移 ≤0.055 SFQ】**
- **为什么输出链有 12Ω**【推断】：限流 + 提供阻尼（没有它，读出电流的振铃更严重）
- **为什么读出是振荡的**【推断，机制一致】：读环是 LC 系统（电感 + 结电容），翻转后能量在 L 和 C 之间交换，形成衰减振荡——实测波形 +74 → −18.7 → +32 → −15.6µA【实测 P0.0】正是阻尼振荡的样子

## 3.3 DCSFQ 输入网络（L1/L2/L3）——每个元件干什么

```
输入 a ──L1(1.67p)── node1 ──L3(0.6p)── node2 ──B1── node3 ──L4── B2 ──…──输出
                    │
                   L2(3.9p) 到地（DC 回流）
```

- **L1**：输入耦合电感——信号从这里进来【推断，按设计意图】
- **L2**：到地电感——提供**直流回流路径**（偏置电流的回路）；同时在高频下它也是一个分流路径【推断，拓扑角色明确】
- **L3**：把输入电流送向结支路【推断，拓扑角色明确】

**为什么输入电流会"进不去"（0.285 问题）**【推断 + 实测】：输入电流在 node1 分两路：L3（到结）和 L2（到地）。偏置环流（IB1 → B1 → L3 → L2 → 地）的方向与输入电流在 L3 上**相反**——输入一进来就"顶着"偏置环流走。实测证据：L3 电流从 −41.9µA（纯偏置）降到 −22.4µA（输入窗口内）【实测 P0.2】。

**极性问题（输入推的是哪个结）**【推断 + 实测一致】：
- 偏置路径：node3 → B1（3→2）→ L3（2→1）→ node1 → L2 → 地
- 输入路径：a → L1 → node1 → L3（1→2）→ node2 → B1（2→3）→ node3 → L4 → B2 → 地
- 输入电流穿 B1 的方向（2→3）**与偏置相反**（抵消）；穿 B2 的方向**与 B2 偏置同向**（叠加）
- 实测一致：B2 相位幅值随输入增长（0.90→1.29 Φ₀），B1 不动【实测 P0.1】

## 3.4 为什么"缩放 IC"是手段而不是全部

- **缩放的目标**：把阈值从 >150µA【实测 P0.1】降到 45-55µA，匹配 BVM 的 68.4µA
- **为什么不能无限缩**：L_J 矛盾（§1.6）——IC 降一半，L_J 翻倍【定律推导】
- **为什么 DCSFQ 的输入网络没有直接踩 L_J 矛盾**【推断，分析】：L_J 矛盾针对"串联电感传递电流"的拓扑（BQ 的输入）；DCSFQ 的输入是**并联分流**（L2 vs L3），电流不是"穿过"结的电感而是"分"给结支路——但分流的代价是耦合效率（0.285）。两种拓扑各有各的账。

# 第 4 章 实验现象解释（每个现象：机制 + 证据 + 标注）

## 4.1 BJs 为什么 +6.27 SFQ 且 0 个快速事件

- **现象**【实测 BASELINE】：R1 读出期间 BJs 净前进 6.27 个磁通量子，但 fast_events = 0
- **机制**【定律】：68.4µA = 1.37×IC，持续 ~40ps——结进入电压态，相位匀速前进
- **为什么 fast_events = 0**【定律 + 计算】：电压态下相位前进速度 = V/Φ₀。若 V ≈ 0.4mV，则每 0.1ps 前进 ~0.02 个 Φ₀，远小于 0.3 的"快事件"判据——**它"慢慢滑"而不是"跳"**。判据本身是项目定义的【实测口径】。
- **为什么是"阻尼"滑移**：没有快速振荡成分（波形平滑）——虽然没装外部刹车，结自身的 RN 提供了部分阻尼【推断】

## 4.2 为什么同样的结，JTL 干净、BJs 滑移

- 差在**外部环境**：JTL 有 70% 偏置 + RB/LRB 刹车【实测：标准元件验证通过】；BJs 无明确偏置 + 无刹车【实测 + 拓扑分析】
- **机制**【推断，与标准 RSFQ 设计方法一致】：70% 偏置意味着输入只需补 30% 就触发、触发后自动回落到 <IC 复位；BJs 没有这个"半只脚"的工作点，输入超 IC 就一路滑下去

## 4.3 为什么 300µA 会一次爆 8 个事件

- **现象**【实测 P0.1】：300µA bump 在上升沿 B3 出 8 个快速事件（~1ps 内）
- **机制**【推断】：300µA 对 225µA 结是明显过驱动（输入电流经耦合后与 ~61% 偏置叠加，显著超过 IC；精确比例取决于实际耦合系数，未单独测定）——翻转后电流仍远超 IC，结停在电压态连续翻转；电感网络的能量注入又加剧了它
- **为什么这对设计重要**：说明"触发 ≠ 恰好 1 个 SFQ"——**过驱动比例是干净的约束**（≤1.5×），这是阈值上界的由来【实测 + 项目设计决策】

## 4.4 为什么 DCSFQ 是边沿触发（持续 148ps 不累积）

- **现象**【实测 P0.1】：bump（28ps）与 sustained（148ps）事件完全一致；B2 相位在保持期恒定 6.76 Φ₀
- **机制**【推断，与拓扑一致】：输入电流主要通过 L 网络的**瞬态**耦合到结支路（电感微分特性：dI/dt 大的边沿耦合强，稳态直流被 L2 短路走）；结触发后 SFQ 从输出链逃逸，结电流回落到 IC 以下复位——持续输入没有持续"泵"结
- **标注**：机制未单独验证（我们没有做"去掉 L2 会怎样"的对照），但与所有观测一致

## 4.5 为什么耦合只有 0.285（理论分流 6.5:1 vs 实测 0.285）

- **理论分流**【定律】：~30GHz 下 L2(3.9p) vs L3(0.6p) 感抗比 ≈ 6.5:1 偏向 L3——理想情况应有 ~85% 电流进结支路
- **实测**【实测 P0.2】：增量耦合仅 0.285
- **差距的原因**【推断】：① 偏置环流与输入方向相反（抵消，见 3.3）；② 结不是线性电感，其小信号阻抗随工作点变；③ 时间尺度上输入边沿（~2ps 上升）的有效频率比 30GHz 更高，L2 的分流比例随频率变化——**方向抵消是主因**（-41.9 → -22.4µA 的直接证据【实测】）
- **标注**：① 有直接实测证据；②③ 是机制推断

## 4.6 为什么 BVM 读出波形是振荡的（+74/−18.7/+32/−15.6µA）

- **现象**【实测 P0.0】：12Ω 负载下读环电流正负交替衰减
- **机制**【推断，机制一致】：读环是欠阻尼 LC 系统——翻转释放能量后，能量在环的电感与结电容之间来回交换，每半个周期换一次方向，直到被电阻（RS=3Ω、RSL=12Ω）耗散
- **为什么对接口重要**：振荡的每个摆动都是"候选边沿"——边沿触发的判别器可能在每个摆动都触发一次（这是 V2 要回答的核心风险）【推断 + 项目风险分析】

## 4.7 为什么写入是"0 → 直接跳 6 涡旋"（没有单涡旋）

- **现象**【实测 P2】：80µA 不写，100/120µA 都直接到 ≈6 涡旋
- **机制**【推断】：写脉冲（100µA/10ps）注入的能量远超"加一个涡旋"所需的能量——环里最终涡旋数由注入能量和环的参数决定，而不是"一个量子一个量子地加"。**为什么恰好 6 而不是其他数**：取决于环的电感（L_M1=12.5p 等）与注入电流的平衡——具体值未单独建模，属于未解问题【推断】
- **为什么重要**：读电流 78µA 对应 +6 涡旋态——只要它稳定可重复（已实测 ✓），判别器照常工作；但"单涡旋存储"的说法不成立【实测】

## 4.8 为什么 120µA 读会擦除写"0"态

- **现象**【实测 P2】：120µA 的 R0 读把 −5.9 涡旋态擦成 ≈0
- **机制**【推断】：读电流过大时，穿过存储环（S-loop）的感应电流超过 JM1/JM2 的翻转阈值，把存储涡旋"冲掉"——就像水压太大把水坝冲垮。**具体电流路径未单独验证**【推断】
- **设计含义**【实测 + 决策】：读驱动 ≤100µA 是硬约束（100µA 读实测非破坏）

## 4.9 为什么 68.4µA 是"链 + BQ 输入"的加载值

- **现象**【实测 P0.0 + BASELINE 复核】：8-JJ 链接地 = 79.55µA；接 BQ 输入 = 68.41µA
- **机制**【定律 + 拓扑】：BQ 的 BJs（IC=50µA）在读出期间进入电压态，分流了 ~11µA——KCL 在链尾节点成立：79.55 − 68.41 ≈ 11.1µA【实测计算】
- **为什么重要**：68.4µA 不是 BVM 的"固有输出"，是特定负载下的值——接口设计必须按负载相关范围（43.9-97.8µA）取裕度【实测 P0.0】
