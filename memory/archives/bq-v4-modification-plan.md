# BQ v4 修改方案

## 一、根因分析

### 1.1 电路信号流

```
IN → Lin(0.8p) → BJs → node2 → L1(3.91p) → node3 → L2(3.91p) → node4 → BJL2 → L0 → OUT
                      ↓                           ↑
                BJL1+RJ1→GND              IBias(35µA) via RB(6Ω)
                (DC回流路径)               (偏置注入)
```

### 1.2 论文 BQ vs 我们的 BQ

| 结 | 论文 (SUST 2024) | 我们的 BQ | 缩放比 |
|----|-----------------|----------|--------|
| 检测结 | JS=**133µA** | BJs=**50µA** | ÷2.7 |
| 回流结 | JL1=**112µA** | BJL1=**36µA** | ÷3.1 |
| 输出结 | JL2=**189µA** | BJL2=**54µA** | ÷3.5 |

### 1.3 核心缺陷：IC 顺序导致信号被吞噬

```
论文: JS(133µA) > JL1(112µA)
     检测结 IC > 回流结 IC → 检测结先触发，回流结后触发 ✅

我们: BJs(50µA) > BJL1(36µA)  ← 但实际 BJL1 仍然先触发！
     因为 BJL1 直接连 node2→GND，BJs 的触发能量经过 BJs 内部阻抗衰减后
     到达 node2 已经减弱，而 BJL1 IC 只有 36µA → 轻松触发 → 能量泄放到地
```

**结论**: 将论文 IC 值等比例缩小 ÷3 时，虽然数学上保持了比例，但**触发的物理阈值不等于简单的 IC 比例**——BJL1 位于 BJs 之后，接收的是已衰减的信号，需要更低的 IC 才能与之匹配。但我们把它的 IC 降得太低了（36µA），反而让它变成了电流黑洞。

## 二、修改方案

### 2.1 设计原则

```
IC 顺序:  BJs(低) < BJL2(中) < BJL1(高)
功能:     检测输入   传递输出   直流回流
触发顺序: 最先       第二       最后
```

### 2.2 具体参数

| 参数 | 当前值 | 新值 | 理由 |
|------|--------|------|------|
| **BJs area** | 0.50 | **0.50** | 不变，IC=50µA 匹配 BVM 输出水平 |
| **BJL1 area** | 0.36 | **0.90** | IC 36→**90µA** (提升 2.5×)，远高于 BJs，不抢信号 |
| **BJL2 area** | 0.54 | **0.70** | IC 54→**70µA** (提升 1.3×)，介于 BJs 和 BJL1 之间 |
| **RJ1** | 33Ω | **56Ω** | RN_BJL1=18Ω, R_eff=18∥56=13.6Ω (保持过阻尼, 但减泄放) |
| **RJ2** | 22Ω | **36Ω** | RN_BJL2=23Ω, R_eff=23∥36=14Ω (保持过阻尼, 提高输出阻抗) |
| **L0** | 1.323pH | **2.5pH** | 更大的 L·dI/dt → 更高 Vout，同时更好的 JTL 匹配 |
| **IBias** | 35µA | **35µA** | 不变，70% of BJs IC |
| **Lin** | 0.8pH | **0.8pH** | 不变 |
| **L1, L2** | 3.91pH | **3.91pH** | 不变 |
| **RB** | 6Ω | **6Ω** | 不变 |

### 2.3 IC 顺序 (修改后)

```
BJs(50µA)  <  BJL2(70µA)  <  BJL1(90µA)
  检测         传递输出         直流回流
  ↓ 先触发     ↓ 第二           ↓ 最后
```

### 2.4 与论文值的关系

| 结 | 论文 | v4 修改后 | v4/论文 |
|----|------|----------|---------|
| JS/BJs | 133µA | 50µA | 38% |
| JL1/BJL1 | 112µA | **90µA** | 80% |
| JL2/BJL2 | 189µA | **70µA** | 37% |

BJL1 被大幅提升（从 32% 论文值 → 80% 论文值），这是最关键的变化。

## 三、预期效果

### 3.1 修改前

```
BJs 翻转 → node2 → BJL1(36µA) 立即触发 → 能量泄放到地 ↘
                 → L1→L2→BJL2(54µA) → 几乎无能量到达 → 输出微弱
```

### 3.2 修改后

```
BJs 翻转 → node2 → BJL1(90µA) 未触发（IC 太高）
                 → L1→L2→BJL2(70µA) → BJs能量到达 → BJL2触发 → SFQ输出 ✓
                 → BJL1 在 BJL2 之后才触发，仅提供 DC 回流
```

| 测试 | 方法 | 预期 |

## 五、风险

| 风险 | 缓解 |
|------|------|
| BJL1(90µA) 过高导致 DC 偏置不稳定 | IBias=35µA 不变，DC路径通过 BJL2 完成 |
| BJL2(70µA) 输出阻抗变化影响 JTL 匹配 | L0 已增大到 2.5pH 改善匹配 |
| 阻尼不足 (RJ1=56Ω, RJ2=36Ω) | 已计算 R_eff < 15Ω，均为过阻尼 |
