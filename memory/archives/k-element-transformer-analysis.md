# K 元件变压器在 BVM→BQ 耦合中的分析

## 一、K 元件是什么

K 元件是 SPICE 中实现**互感耦合**的标准语法。它耦合两个电感，通过互感 M 传递能量。

```spice
L_PRI nodeA nodeB 2p     ← 初级电感
L_SEC nodeC nodeD 8p     ← 次级电感
K_TX L_PRI L_SEC 0.9     ← 耦合系数 K=0.9
```

### 物理模型

```
   I_PRI →               → I_SEC
  ┌─L_PRI─┐         ┌─L_SEC─┐
  │       │    M    │       │
  └───────┘  ←──→  └───────┘
  
  M = K × √(L_PRI × L_SEC)     互感 [Henry]
  n = √(L_SEC / L_PRI)          匝数比 [无量纲]
  
  理想变压器:
    V_SEC = V_PRI / n           (电压变换)
    I_SEC = n × I_PRI           (电流变换)
    Z_in  = Z_load / n²         (阻抗变换)
```

## 二、为什么选择 K 元件解决 BVM→BQ 耦合

### 动机

BVM SL 输出阻抗 ~130Ω, BQ 输入阻抗 ~350Ω。阻抗不匹配导致 ~27% 电流传递。
变压器可同时提供:
1. **阻抗变换**: Z_in = 350/n² → 对 n=2, Z_in=87.5Ω, 更接近 130Ω
2. **电流放大**: I_SEC = n×K×I_PRI

### 设计参数

```
n=2 (L_PRI=2pH, L_SEC=8pH), K=0.9
预期: I_BQ = 2×0.9×I_PRI = 1.8×, 阻抗匹配改善到 87.5Ω
```

## 三、实验与失效分析

### 实验配置 (并联)

```
SL→8×jjmit→nld8→L_PRI→GND  (初级)
L_SEC→IN_BQ→GND              (次级, 并联)
```

| n | L_PRI | L_SEC | I_PRI | I_SEC | I_SEC/I_PRI | 结果 |
|----|-------|-------|-------|-------|-------------|------|
| 2.0 | 2pH | 8pH | 75µA | 16µA | 0.21× | ❌ |
| 2.5 | 2pH | 12.5pH | ~94µA | 26µA | 0.28× | ❌ |
| 3.0 | 2pH | 18pH | ~94µA | 23µA | 0.24× | ❌ |

### 实验配置 (串联注入)

```
SL→8×jjmit→nld8→L_PRI→GND     (初级)
nld8→L_SEC→IN_BQ               (次级, 串联注入)
```

| n=2.0 | I_PRI=94µA | I_SEC=24µA | 0.26× | ❌ |

### 失效原因分析

**原因 1: SFQ 时间尺度不匹配**

K 元件变压器基于**正弦稳态**模型(V = jωM·I), 但 SFQ 脉冲是 **ps 级瞬态事件**。

```
正弦稳态 (MHz-GHz):  能量在多个周期内传递, 耦合效率高
SFQ 脉冲 (~2ps):     单次瞬态事件, 磁场来不及建立稳定耦合
```

在 2ps 内, 电磁波在真空中的传播距离仅 0.6mm, 互感磁场的建立需要 τ ~ L/R ~ 2p/130 = 0.015ps (远小于 2ps)。因此建立速度不是问题。

**原因 2: 互感 M 太小**

```
M = K√(L_PRI×L_SEC) = 0.9×√(2p×8p) = 3.6pH

在 500GHz 下: Z_M = ωM = 11.3Ω
BVM 输出电压 ~800µV (peak)
次级感应电压: V_SEC = ωM×I_PRI = 11.3 × 75µA = 0.85mV
次级负载阻抗: L_SEC(25Ω) ∥ BQ_in(350Ω) ≈ 23Ω
I_SEC = 0.85mV/23Ω ≈ 37µA

但实测仅 16-24µA —— 实测值低于理论值
```

**原因 3: L_PRI 与 SL 负载并联分流**

L_PRI=2pH 在 500GHz 下 Z≈6.3Ω。而 8×jjmit(area=5) 负载堆叠的总阻抗更高。
SL 电流主要**绕过** L_PRI 经负载堆叠到地, 只有少部分通过 L_PRI 产生磁场。

```
SL ──┬── 8×jjmit(Z≈200Ω) ── GND     ← 大部分电流走这条路
     └── L_PRI(Z≈6.3Ω) ── GND        ← 只有 ~3% 走这条路
```

## 四、K 元件的适用范围

K 元件变压器适用于:
- **连续正弦波耦合** (MHz-GHz 范围)
- **谐振电路** (利用 LC 谐振增强耦合效率)
- **DC-DC 变换** (慢速电流放大)

K 元件变压器不适用于:
- **ps 级 SFQ 脉冲耦合** (瞬态能量传递效率太低)
- **需要高 K 值的场景** (SPICE K 系数的上限是 1.0, 但实际超导电路中 K>0.95 很难实现)
- **宽带匹配** (变压器带宽受限于 Q 值)

## 五、为何在 BVM→BQ 场景中放弃

```
放弃原因总结:
1. 实验: 4个配置 (并联n=2/2.5/3, 串联n=2) 全部失败
2. 理论: M=3.6pH 在 ps 时间尺度传递效率 < 30%
3. 结构: L_PRI 与 SL 负载并联 → 严重分流 → 有效磁场减弱
4. 对比: 论文 (2507.04648) 未使用变压器, 说明直接耦合可行
```

可能的改进方向（如果未来需要重试）:
- L_PRI 串联在 SL 路径中（而非并联）
- 使用更高 L_PRI 值 (10-20pH) 提高 M
- 使用 LC 谐振增强特定频率的耦合
- 改为超导量子干涉器件 (SQUID) 耦合代替 K 元件
