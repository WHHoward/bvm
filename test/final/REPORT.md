## 一、项目目标

在 JoSIM 中复现 BVM（双稳态涡旋存储器）和 QB（量化缓冲器）电路，
实现 BVM 存储/读出 → QB 量化 → SFQ 脉冲输出的完整链路，
为 MVM（矩阵-向量乘法）仿真奠定基础。

## 三、QB 单元

### 3.1 原始配置 vs 最终配置

| 参数 | Synapse 论文原值 | 我们的最终值 | 改动原因 |
|------|-----------------|------------|---------|
| JS IC | 133 μA | **25 μA** | 匹配 BVM 单 cell 输出 (32μA) |
| JS 阻尼 | RN=1.9Ω (βc≈1.1) | **R_shunt=10Ω 并联 (βc≈0.28)** | 抑制 LC 振荡, 产生离散 Φ₀ |
| IBias | 未指定 | **40 μA** | 保持 JL1/JL2 偏置 |
| JL1 IC | 112 μA | 112 μA | 不变 |
| JL2 IC | 189 μA | 189 μA | 不变 |
| RB | 8.5 Ω | 8.5 Ω | 不变 |
| Lin/L1/L2/L0 | 0.8/3.91/3.91/1.323 pH | 不变 | 论文固定 |
| 输入脉宽 | — | **10 ps** | 匹配 BVM 50GHz 操作 |

### 3.2 关键改动：C1 — JS 并联分流电阻

**问题**: QB 的 JS 结开关后，LC 环路（Lin+L1+L2+L0 ~ 10pH, C_JS ~ 0.15pF）持续振荡，
导致相位连续累积（无离散 2π 台阶）。

**解决**: 在 JS 两端并联 10Ω 电阻，将有效 RN 从 10Ω 降至 5Ω，
McCumber 参数 βc 从 1.14 降至 0.28（深度过阻尼），LC 振荡在一个周期内衰减。

**效果对比**:

| 指标 | 无 shunt (βc≈1.1) | R_shunt=10Ω (βc≈0.28) |
|------|-------------------|----------------------|
| 32μA → Φ₀ | 4.3 Φ₀ (过度) | **1.0 Φ₀** (理想) |
| V_JS 脉冲间复位 | 不复位 | **|V|<0.17mV** |
| 相位行为 | 连续斜坡 | **准离散台阶** |

### 4.3 论文分析关键发现

| 发现 | 来源 | 影响 |
|------|------|------|
| BVM 同列多行同时读，电流在 SL 累加 | MVM + BVM | QB 接收模拟累加电流 |
| QB 按电流幅度→脉冲数 (1x→1脉冲) | MVM §2.2 | 需线性响应 |
| QB 需"调整"以检测单 BVM 输出 | BVM §3.2, MVM | 我们的 JS 调整有论文依据 |
| JSL 替换 LSL 推荐 | BVM §2.5 | 面积优化，非性能提升 |
| 论文未给 I_SL 数值目标 | — | 32μA 可接受 |
| MVM 用 JoSIM 得到 0-4 脉冲 | MVM Fig.2b | QB 在 JoSIM 下应能工作 |

## 六、已知问题与下一步

### 残存问题

1. **QB 线性度**: 96μA→3.6Φ₀ (应3Φ₀), 128μA→5.3Φ₀ (应4Φ₀)。高电流级相位过度累积。
   - 方向: R_shunt 精细调优 (7-15Ω扫描) 或非线性分流
2. **V_JS 峰值低**: 32μA 时仅 0.19mV。低于标准 SFQ 脉冲 (0.7mV)。
   - 方向: 需验证后级 T1 能否检测
3. **BVM+QB 未直连测试**: 目前用理想电流源模拟 BVM 输出
   - 方向: 连接真实 BVM SL 到 QB 输入

### 下一步

1. **C3**: 连接 BVM SL → QB, 验证论文方案
2. **C4**: R_shunt 精细扫描 (7-15Ω) 改善线性
3. **T1**: 开始 T1 加法器仿真
