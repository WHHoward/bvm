## 分流标定 (68.4µA bump, .tran 0.1p 200p, 1999 采样)

| 量 | 峰值 | @时刻 |
|---|---|---|
| I(L1) 端口输入 | 68.40µA | 12.0ps |
| I(L2) 到地 | 91.62µA | 14.5ps |
| I(L3) B1/B2 支路 | 42.92µA（负号，流向 2→1） | 45.0ps |
| V(OUT1) | 65.1µV | 4.1ps |

**分流系数 = I(L3)pk/I(L1)pk = 42.92/68.40 = 0.627**（期望 0.5-0.9 范围内）

**重要时间点澄清（观察）**: I(L3) 峰值发生在 t=45ps——bump 下降沿结束时刻，输入已为 0。该时刻 I(L3)=-42.92µA 等于**无输入基线环流**（t>45ps 稳态 I(L3)=-41.9µA, I(L2)=+41.9µA，偏置驱动的环路电流）。因此峰值比值 0.627 被基线环流主导，**不代表输入电流的实际分流**。

输入窗口内 (12-40ps) 稳态（纯测量）:

| 时刻 | I(L1) | I(L2) | I(L3) |
|---|---|---|---|
| 无输入 (t>45ps) | 0 | +41.9µA | -41.9µA |
| 输入窗口 (t=30ps) | +68.4µA | +90.8µA | -22.4µA |

- 节点 1 KCL: I(L1) = I(L2) + |I(L3)| → 68.4 = 90.8 - 22.4 ✓
- 输入增量效应: ΔI(L2)=+48.9µA（71% 入地），ΔI(L3)=+19.5µA（29%，且方向与偏置环流相反——输入**减小**了 L3 支路电流）
- **输入窗口内比值 I(L3)/I(L1) = 22.4/68.4 = 0.327**；**增量分流 ΔI(L3)/ΔI(L1) = 19.5/68.4 = 0.285**
- I(L2)/I(L1)（到地分流）= 91.62/68.40 = 1.340（峰值）/ 90.8/68.4 = 1.327（窗口稳态）
