### Task 1: 创建 bq_cell_v4.cir (S1.1)

**Files:**
- Create: `circuits/qb/bq_cell_v4.cir`

- [ ] **Step 1: 写 v4 单元**

```spice
* BQ Buffer Cell v4 — IC order fix (BJL1 was current sink at IC=36uA)
* Root cause: BJL1(36uA) < BJs(50uA) → 回流结先触发, 吞噬信号
* v4: IC order BJs(50uA) < BJL2(70uA) < BJL1(90uA)
*   BJL1 IC 36→90uA (2.5x) — 不抢信号, 仅 DC 回流
*   BJL2 IC 54→70uA (1.3x) — 传递输出
*   RJ1 33→56, RJ2 22→36 — R_eff≈13-14Ω 保持过阻尼, 减小泄放
*   L0 1.323→2.5p — 更大 L·dI/dt → 更高 Vout, 改善 JTL 匹配
*
* NOTE: 独立测试用 IBias=35uA; 输入脉冲 90uA/5ps 应产出 ≥1 SFQ。

.subckt BQ IN OUT IB

Lin IN 1 0.8p
L0 4 OUT 2.5p
L1 2 3 3.91p
L2 3 4 3.91p
BJs 1 2 jjmit area=0.5
BJL1 2 0 jjmit area=0.90
RJ1 2 0 56
BJL2 4 0 jjmit area=0.70
RJ2 4 0 36
RB IB 3 6

.ends BQ
```

### 关键对照 (同测试台 90µA)

| 单元 | 无 JTL V(OUT1) pk | 有 JTL V(OUT1) pk | JTL B1 收到 |
|------|-------------------|-------------------|-------------|
| v2 (旧) | **1035µV** (基线记录) | 325µV | +0.70 (0 fast) |
| v4 (新) | **186µV** | 124µV | +0.68 (0 fast) |

**v4 输出比 v2 差 5.5×** — 提高 BJL1/BJL2 IC 消除了吞噬，但同时也消灭了输出传递路径。

### 冻结的根因 (3 条)

1. **BJs 输入级**: 无分流电阻 + βc≈5.4 欠阻尼 → 任何过驱动 (70µA = 1.4×IC 即触发) 都进入持续电压态滑移 (602-829 SFQ / 300ps), 从未产生干净单翻转
2. **v4 IC 顺序修正的副作用**: BJL1(90µA) 不再吞噬 ✅ 但 BJL2(70µA) 在 ≤90µA 下从不触发 → 能量困在 BJs 滑移环路, 无输出
3. **输出级驱动能力**: v2/v4 均无法驱动 250µA ColdFlux JTL (L0 阻抗分流, 输出脉冲电流 ~100µA < JTL 阈值)
